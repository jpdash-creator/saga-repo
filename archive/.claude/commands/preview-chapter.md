# `/preview-chapter`

Corresponds to canon command `[PREVIEW CHAPTER]` (C-31). Read-only — assembles the current
Chapter's already-written prose units in order for review, without writing/concatenating the
Chapter's per-Prose files into an output document (see `/export-chapter` for the real file output).
