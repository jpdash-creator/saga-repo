# `/character-sheet`

Corresponds to canon command `[CHARACTER SHEET: name]` (C-19). Read-only synthesis of
`/review-ledger`'s raw data into a human-friendly summary (identity, classification, power/
capability, ideology, psychology, consequence arc, relationships, resources, narrative role,
recent canon events) — does not alter the ledger.
