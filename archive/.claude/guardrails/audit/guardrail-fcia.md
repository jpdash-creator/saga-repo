# Guardrail: FCIA — Full Content Integrity Audit

**Source:** Part 1 (Governance and Audit Law), Area 8.12
**Applies to:** Continuity Checker (primary owner); Prose Maker (must satisfy it)

## The rule

FCIA audits **narrative prose content** — the actual written chapters/areas/prose units —
against 16 content dimensions (FC-1–FC-16), and runs on **every accepted prose unit and
every session end**, not on a sample.

The 16 dimensions: Cultivation, Technology, Synergy, Character Arc, World/Location,
Information/Secrecy, Affiliation/Social, Ideology/Psychology, Consequence, Combat, Ledger
State Consistency, NSA (knowledge-graph) Propagation, Cross-Event Continuity, End-of-Session
state, **FC-15 Contextual Earning Audit** (Part 28 Area 15's Three-Beat Test — has this
moment been narratively earned, not just stated), and **FC-16 Novel Thematic Compliance**
(Part 36's Check #16 — see `quality/guardrail-tier0-narrative-quality.md`).

## Hard rules

- 14 triggers (FT-1–FT-14) fire FCIA — not just "chapter complete," but also things like a
  new named entity appearing, a ledger-relevant state change, or a cross-Part dependency
  being touched for the first time.
- **14 triggers (FT-1-FT-14) run FCIA before any narrative claim is trusted** — a Prose
  Maker output is a draft until FCIA (via Gate 1) has cleared it.
- Session close always runs FCIA end-of-session, then ALCA Mode B, then a Unified Audit
  Summary — never skip straight to "done" without this chain.
- **Reader-Reveal Timing Law (RRTL)** is audited as part of FCIA: villain motivation must
  surface by the hero's Arc Phase 4, the hero's core wound by Phase 3, faction agendas one
  Section before climax, and consequences are never concealed indefinitely.

## Escalation

An FCIA FAIL routes back through the Gate 1 Correction Protocol
(`audit/guardrail-audit-gate-law.md`) — it is never waived because a deadline or pacing
preference makes revision inconvenient.
