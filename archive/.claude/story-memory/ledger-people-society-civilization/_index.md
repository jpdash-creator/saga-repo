> **Purpose:** This folder tracks the canonical state of civilizations that appear in the novel. For each civilization, it records: CTD (Civilization Tier Designation per Part 21), CCT (Composite Civilization Tier), five-axis assessments (CA/TA/EA/LA/SA), Cultural Paradigm Type (CPT), dominant social structures, and any active civilizational events (CTD transitions, cultural paradigm shifts, TA tier breakthroughs, inter-civilization conflicts). This folder also holds cultural state information (dominant CPC class, inter-culture tensions, social stratification events) for cultures that appear in the narrative.

> **When to Create a New Civilization File:** When a named civilization first appears in prose with enough detail to warrant classification, or when a civilization's state changes in a way that affects the narrative.

> **Update Protocol:** Per Part 1 Area 6, the Pre-Write Ledger Check reads civilization state before any prose set within or involving a specific civilization. CTD transitions, TA axis tier breakthroughs, and CCT reclassification events trigger mandatory Post-Write Ledger Update. Cultural paradigm shifts and inter-culture contact events that alter the narrative fabric also trigger updates here.

> **Command Interface:** [STATUS] (C-13) reports current civilization context from this ledger. [RUN CANON AUDIT] (C-10) includes civilization ledger state in cross-event consistency check.

> **CS%/TS% Tracking:** CS% (Cultivation Synergy %) and TS% (Technology Synergy %) for each civilization are Living Information (L) stored in Civilization Ledger Section 2 (Power Axes) per Part 31 Area 21.9. Values range 0%–100% and are governed by the civilization's CTD (Civilization Tier Designation per Part 21), CuA-C axis, and TA axis. The _index.md registry includes CS%/TS% columns for quick-reference. Reference ranges by CTD are authored in Part 31 Area 21.9 (20-tier CTD ladder, CCT-1 Subsistence through CCT-20 Absolute) and mirrored in Part 21 Section 3.2.1 as a Quick-Reference Band Table (consolidated in Part 31 Area 21.9). Updates triggered by CTD transitions, major TA or CuA-C axis shifts, Sacred Ground network changes, and cultural paradigm shifts (Part 25) that reorient the civilization's paradigm investment.

## Part 28 Area 17 — Lore Section Schema (Civilization Domain)

**Added:** 2026-04-19 (formal Canon amendment — schema expansion pass).
**Governing Law:** Part 28 Area 17 (Lore Creation Law). **Audit Hook:** Part 1 Area 8.13 ALCA dimension AL-10 (Lore Completeness Alignment).

**Mandate:** Every civilization entity file must carry a dedicated **Section 5 — Lore (Part 28 Area 17)** block populated to the Breadth-and-Depth Standard.

**Required Axes (Minimum Lore Fields per Part 28 Area 17.2 — Civilization):**

1. **CCT Tier and Civilization Type** — CS / TS / BP / ES / LS / CP per Part 21 Area 6.
2. **Dominant Languages and Writing Systems** — named, with script family where known.
3. **Calendar System** — epochs, year-reckoning, named festivals anchoring the calendar.
4. **Religious/Philosophical Framework** — pantheon (named deities if any), cosmology, ethical system, named sacred texts.
5. **Kinship Structure** — family/clan/lineage organization, inheritance rules, named ruling lineages.
6. **Economic Paradigm** — subsistence, redistributive, mercantile, tributary, post-scarcity, per CCT context.
7. **Technology Stance** — Part 8 TA posture (promotion, restriction, monopoly, openness); named technology institutions where applicable.
8. **Cultivation Stance** — Part 3/4 posture (meritocratic, aristocratic, forbidden, mandatory); named cultivation academies or sects where applicable.

**Depth Test (Part 28 Area 17.3):** "Can I write a 1800%-immersion scene set within this civilization using only what is in the ledger?" If yes, depth is satisfied.

**Silent Overwrite Prohibition (Part 28 Area 17.5):** Once civilization lore is recorded, it is fixed under the Establishment Threshold.
