> **Purpose:** This folder contains one ledger file per primary villain/antagonist character in the Starward Saga series. Each file uses the 10-section Character Ledger Template defined in Part 1 Area 5.4. Section 5 (Psychological Profile) uses Part 18's five villain psychological archetypes (The Hollow, The Calcified, The Consumed, The Converted, The Divided). Section 9 (Arc Status) records villain arc phase (Part 18), defeat type (Part 18), and survival status.

> **Critical Note:** Per Part 18 Rule 18.1.3.1, villain characters have no survival protection — death is a canonical outcome. When a villain's status changes to "Dead," the ledger file is preserved as permanent canon record but is marked Inactive.

> **Update Protocol:** Per Part 1 Area 6 (Ledger Audit and Update Law), this index is updated every time a new villain ledger file is created or an existing villain's status changes. The Pre-Write Ledger Check (Area 6.2) reads villain ledger entries before any prose unit where the villain appears. The Post-Write Ledger Update (Area 6.3) updates villain ledger entries after any accepted prose unit that changes villain state.

> **Mandatory Update Triggers:** CSS-5+ consequence accumulation; villain power shift; arc phase progression; defeat event; resource or faction position change; ideology shift; CS%/TS% triggering events per Part 31 Area 21.4.2 (Integration Model change, realm breakthrough, major CI Technology access change, Sacred Ground access gained/lost).

> **CS%/TS% Tracking:** CS% (Cultivation Synergy %) and TS% (Technology Synergy %) for each villain are Living Information (L) stored in Character Ledger Section 2. Values range 0%–100% per Part 31 Area 21. The _index.md registry includes CS%/TS% columns for quick-reference audit. An Integrated Practitioner villain with high CS% and TS% (e.g., CS% 75%+, TS% 70%+) represents one of the most dangerous villain configurations per Part 31 Area 12.

## Part 28 Area 17 — Lore Section Schema (Character Domain — Villain)

**Added:** 2026-04-19 (2026-04-19 formal Canon amendment — schema expansion pass).
**Governing Law:** Part 28 Area 17 (Lore Creation Law). **Audit Hook:** Part 1 Area 8.13 ALCA dimension AL-10 (Lore Completeness Alignment).

**Cross-Reference Alignment:** Per Part 28 Area 17.2 (Character): "Villains (Part 18) require comprehensibility-sufficient depth." The 10-section Character Ledger Template (Part 1 Area 5.4) is the schema; Section 5 uses Part 18's five villain psychological archetypes.

**Mandate:** Every villain ledger file must populate Sections 1–10 to at least **comprehensibility-sufficient depth** per Part 28 Area 17.3 and Part 18. The Depth Test for villains: "Can a reader, from the ledger alone, understand *why this villain does what they do* — not merely that they oppose the heroes?" If yes, depth is satisfied.

**Required Axes — Villain-Specific Focus (beyond standard character axes):**

1. **Psychological Archetype** — Hollow / Calcified / Consumed / Converted / Divided (Part 18) with named origin event.
2. **Ideological Core** (Part 20) — what the villain believes, and what personal cost proves they believe it.
3. **Capacity and Resources** — Part 3 realm, Part 5 combat profile, faction backing, Part 12 relics, Part 33 weapons, Part 32 vehicles.
4. **Known Victims and Consequences** (Part 27 CSS) — named prior consequences the villain has caused, with CSS tier where known.
5. **Defeat Conditions** (Part 18 Area 5) — what would constitute the villain's defeat type (conversion / capture / death / self-destruction / exile) and the minimum hero phase required per Rule 18.5.3.
6. **Open Tensions** — at least one unresolved question that future prose can resolve (revelation pending, relationship reversal possible, protégé poised to inherit).
7. **Innate Moves (Part 6 Area 12)** — required Section 3 subsection for all villain ledgers per Part 1 Area 5.4 v2.5. Villains who are non-species-innate (pure-human or non-hybrid cultivator villains) record "(none registered — character is non-species-innate type)". Villains who are hybrid sentients (Part 16 Area 17), bipedal sentient species members (Part 16 Area 18), or other sentient beings (Part 16 Area 19) register their S-3 and S-8-with-S-3 moves with full Part 6 Area 12.3.5 field set. Villain S-3 moves carry the same Firmament-Lock immunity as hero S-3 moves (Part 6 Area 12.3.4) — this is a substrate fact, not a character-moral fact.
8. **Species Classification (Part 16 Areas 17–19)** — if applicable, villain's species designator (e.g., Minotaur-Lineage Balanced-Fusion Hybrid; Bipedal Sentient Species — Avian-Lineage), SADS position for species-innate-capable villains, and species-cultural affiliations.

**Silent Overwrite Prohibition (Part 28 Area 17.5):** Once villain lore is recorded, it is fixed under the Establishment Threshold. Post-Part 18 Area 1.5 villain redemption arcs require a formal Canon amendment before ledger rewriting.
