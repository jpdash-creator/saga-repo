> **Purpose:** This folder contains ledger files for Tier A (deep) side characters per Part 19's Three-Tier Depth Spectrum. Tier A characters receive full individual ledger files using the 10-section Character Ledger Template. Tier B and Tier C characters are tracked as abbreviated entries directly in this _index.md rather than separate files.

> **Tier Definitions (Per Part 19 Area 2):**
> - **Tier A:** Deep-depth side characters with substantial independent arcs, explicit psychological profiles, and narrative functions that can generate CSS-5+ events. Require full ledger files.
> - **Tier B:** Moderate-depth characters with defined roles but limited arc scope. Tracked here in the index with abbreviated profiles (name, function, current status, key relationships).
> - **Tier C:** Functional/background characters with minimal narrative complexity. Tracked in the index with single-line entries.

> **Critical Rules:**
> - Mentor Death (Part 19 Rule 19.2.1.1) = CSS-7+ permanent event — requires immediate ledger update and [CONSEQUENCE AUDIT] C-18.
> - No unresolved Tier A character threads at arc close (Part 19 Rule 19.9.3.2).
> - CS%/TS% values for Tier A characters are tracked in their full ledger file Section 2 and summarized in the Tier A registry table here. Tier B characters include CS%/TS% in their abbreviated registry row. All values per Part 31 Area 21.4.

> **Update Protocol:** The Pre-Write Ledger Check (Part 1 Area 6.2) reads Tier A side character ledger entries before any prose where they appear. The Post-Write Ledger Update (Part 1 Area 6.3) updates entries after any narrative function event, death, status shift, or significant relationship change.

## Part 28 Area 17 — Lore Section Schema (Character Domain — Side Character)

**Added:** 2026-04-19 (2026-04-19 formal Canon amendment — schema expansion pass).
**Governing Law:** Part 28 Area 17 (Lore Creation Law). **Audit Hook:** Part 1 Area 8.13 ALCA dimension AL-10 (Lore Completeness Alignment).

**Cross-Reference Alignment:** Per Part 28 Area 17.2 (Character) and Part 19: Side characters follow the **Three-Tier Depth Spectrum (A/B/C)**. Each tier has a different depth ceiling — the Depth Test applies at each tier's own level, not universally.

**Per-Tier Axis Requirements:**

**Tier A (full ledger file, 10-section template, Section 3 includes Innate Moves subsection):**
- Sections 1–10 populated.
- Depth Test: "Can a 5000%-depth scene be written from only this ledger?"
- Additional: Narrative Function (what structural role this character plays — mentor / foil / catalyst / guardian / traitor-in-waiting) + Termination Plan (how and when this arc is expected to close, per Part 19 Rule 19.9.3.2).
- **Section 3 Innate Moves subsection (Part 1 Area 5.4 v2.5, Part 6 Area 12):** required for all Tier A side character ledger files. Non-species-innate characters record "(none registered — character is non-species-innate type)". Hybrid sentient side characters (Part 16 Area 17), bipedal sentient species members (Part 16 Area 18), or other sentient beings (Part 16 Area 19) register S-3 and S-8-with-S-3 moves per Part 6 Area 12.3.5.
- **Species Classification (Part 16 Areas 17–19):** if applicable, the Tier A side character's species designator, SADS position, and species-cultural affiliations are recorded in Section 1/Section 2 per Part 16 Area 18 and extended character ledger schema.

**Tier B (abbreviated index row):**
- Name, Narrative Function, Current Status, Key Relationship to Hero, CS%/TS% (if narratively tracked), at least one named defining trait.
- **Species-Innate Summary field:** if the Tier B character is a species-innate-capable entity (bipedal sentient, hybrid sentient, other sentient being per Part 16 Areas 17–19), a single-line summary of their most-used S-3 move and its anatomical derivation. Otherwise omit.
- Depth Test: "Can this character execute their narrative function in a scene from only this ledger row?"

**Tier C (single-line index row):**
- Name, Role/Function, Status.
- Depth Test not required; Tier C characters are functional background.

**Promotion Rule:** A Tier B or C character who accumulates significant narrative weight must be promoted to the next tier, with corresponding lore expansion at Gate 2 in the Prose that performs the promoting event.

**Silent Overwrite Prohibition (Part 28 Area 17.5):** Once side character lore is recorded at any tier, it is fixed under the Establishment Threshold.
