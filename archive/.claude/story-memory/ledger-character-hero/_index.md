> **Purpose:** This folder contains one ledger file per protagonist hero character in the Starward Saga series. Each file uses the 10-section Character Ledger Template defined in Part 1 Area 5.4. Sections marked (B) contain Base Information — immutable foundational data established at character creation. Sections marked (L) contain Living Information — continuously updated as prose is written.

> **Update Protocol:** Per Part 1 Area 6 (Ledger Audit and Update Law), this index is updated every time a new hero ledger file is created or an existing hero's status changes. The Pre-Write Ledger Check (Area 6.2) reads hero ledger entries before any prose unit involving that hero. The Post-Write Ledger Update (Area 6.3) updates hero ledger entries after any accepted prose unit that changes hero state.

> **Mandatory Update Triggers (Per Part 17 Area 10.1):** Cultivation/tech breakthrough; significant combat outcome; IE-4+ ideology event; PIS-4+ psychological event; CSS-5+ consequence event; significant relationship change; faction position change; CS%/TS% triggering events per Part 31 Area 21.4.2 (Integration Model change, realm breakthrough, Sacred Ground extended cultivation, CI Technology architectural integration or loss).

> **CS%/TS% Tracking:** CS% (Cultivation Synergy %) and TS% (Technology Synergy %) for each hero are Living Information (L) stored in Character Ledger Section 2. Values range 0%–100% per Part 31 Area 21. The _index.md registry includes CS%/TS% columns for quick-reference audit against the full ledger file.

> **Phase 1 End-State Power Levels (Part 30 Section 1.3.1 — Locked Canon):** All 8 hero ledgers now carry canonical Phase 1 end-state cultivation levels in Sections 2 and 9. These are Locked Canon per Part 28 and govern the Phase 1 story trajectory. The "Phase 1 End-State" column below reflects these targets for quick-reference.

**Silent Overwrite Prohibition (Part 28 Area 17.5):** Once hero lore is recorded in any Section, it is fixed under the Establishment Threshold.
