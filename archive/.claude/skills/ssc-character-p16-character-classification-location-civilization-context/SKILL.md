## Area 9 — Character Classification by Location and Civilization Context

### 9.1 — Location-Based Character Context

A character's location (Part 13) is a primary context that shapes what character types are possible, what cultivation environments are available, and what social class systems govern them.

**Location-Character Context Table:**

| Location Type (Part 13) | Character Context | Dominant Character Types Available |
|------------------------|------------------|-------------------------------------|
| **Village / Settlement** | Mortal-T1 dominated; basic cultivation access; cultivation hierarchy begins here | Village Elder, Farmers, Junior Cultivators, Outer Disciples, Street Merchants, Village Guard |
| **Town** | Mortal T2 Senior–Warrior dominant; small sects present; technology Tier 2–3 access | Sect disciples, small military units, merchants, craftsmen, local officials |
| **City** | Mortal T2 Champion–Ruler; medium sects; technology Tier 3–5; commercial density | Captains, Masters, Commercial Guilds, City Officials, Senior Scholars, Established Merchants |
| **Capital** | Mortal T2 Ruler–Monarch; major sects present; Core Formation available; technology Tier 5–7 | Generals, Grand Elders, Court Officials, Merchant Princes, High Scholars, Intelligence Operatives |
| **Kingdom / Empire** | Xiantian to Core Realm; dominant cultivation powers; full technology-cultivation hybrid possible | Grand Generals, Sect Masters, Grand Scholars, Rulers, Diplomatic Corps |
| **World** | Core Realm to early Divine; civilization-scale military; CCT-4+ technology | Marshals, Ancestors, Grand Scholars, World Rulers, Fleet Captains (Orbital) |
| **Star System** | Divine Realm presence; CCT-5–6 technology; interplanetary military | Divine Commanders, Fleet Admirals, Interstellar Merchants, AI Governance Specialists |
| **Star Cluster / Galactic** | Core-Divine cultivation standard; Tier 8–11 technology; galactic military | Fleet Admirals, Grand Generals, Alliance Directors, Galactic Merchants |
| **Sacred Ground (Area 14, Part 13)** | Special cultivation context; S-Grade 1–8 determines character types present; rare specialists | Formation Masters, Cultivation Physicians, Sacred Site Guardians, Transcendence-Seekers |

### 9.2 — Civilization-Type Character Profiles

A character's civilization type (Part 21) shapes which character categories are dominant, respected, and institutionally supported.

| Civilization Type (Part 21) | Dominant Character Types | Suppressed Character Types |
|----------------------------|--------------------------|---------------------------|
| **CS-Type (Cultivation Sovereign)** | Combat Cultivators, Sect Masters, Elders, Formation Masters, Pill Cultivators | Pure Technology Operators, Non-Cultivator Scholars |
| **TS-Type (Technology Sovereign)** | Combat Soldiers, Engineers, Scientists, Pilots, AI Specialists | Non-integrated Cultivators (seen as backward) |
| **BP-Type (Balanced Practitioner)** | Integrated Practitioners, Hybrid Military, Scholar-Cultivators, Synergy Specialists | Extremists of either pure path |
| **ES-Type (Energy Sovereign)** | Resource Cultivators, Formation Masters, Alchemists, Energy Engineers | Non-resource-focused types |
| **LS-Type (Legacy Sovereign)** | Lineage Keepers, Sect Masters, Noble Houses, Ancestry-Scholars | Innovation-focused characters |
| **CP-Type (Conquest Predatory)** | Combat Specialists, Military Commanders, Assassins, Enforcers | Commercial, scholarly, artistic characters |
