## Area 13 — Vehicle and Infrastructure Integration

### 13.1 — Vehicle-Infrastructure Dependency

Every vehicle class operates within its required infrastructure ecosystem. A vehicle deployed outside its infrastructure context suffers capability degradation:

| Vehicle Class | Required Infrastructure | Without Infrastructure |
|---|---|---|
| ST-Band rail vehicles | Rail network | Non-functional |
| ST-Band ships | Port infrastructure | Limited range (open-sea survival only) |
| OS-Band vessels | Orbital stations; refueling infrastructure | Single-mission only; no sustained operations |
| IS-Band FTL | Navigation beacons; FTL relay network; refueling stations | ±30 AU navigation error per 100 ly; 50% effective range reduction |
| GT-Band vessels | Gate network; galactic beacon network | Transit time multiplied 100–1,000×; effectively unable to function as designed |
| CHV-B/D | CPM supply chain; formation maintenance practitioners | Formation degradation; 5–10% per month capability loss |

### 13.2 — Infrastructure Tiers and Vehicle Classes

Part 15's Infrastructure Tiers (Area 16) directly govern which vehicle classes can operate efficiently in each infrastructure environment:

| Infrastructure Tier (Part 15) | Tier Name | Optimal Vehicle Band | Notes |
|---|---|---|---|
| I | Local Roads | ST-Band Tiers 1–2 | Animal and early mechanical; road-constrained |
| II | Regional Networks | ST-Band Tiers 2–3 | Rail and organized maritime |
| III | National/Continental Grids | ST-Band Tiers 3–4 | Motorized national networks |
| IV | Planetary Integration | ST-Band Tier 5 | Global unified transit system |
| V | Orbital/Interplanetary Hubs | OS-Band Tiers 5–6 | Full inner-system capability |
| VI | Stellar System Beacon Network | OS-Band Tier 7 / IS-Band Tier 8 | Full stellar system + early interstellar |
| VII | Interstellar FTL Lanes | IS-Band Tiers 9–10 | Multi-star network |
| VIII | Galactic Gate Networks | GT-Band Tier 11 | Galaxy-spanning gate infrastructure |
| IX | Cosmological Transit Network | GT-Band Tiers 12–14 / CT-Band | Beyond-galactic infrastructure |
