### 35.4 — Table Updates Required in Other Parts

When authoring or updating other Parts that reference Part 8 technology tiers, the following specific reference updates are required:

**Part 3 (Cultivation Power Law):** The cultivation-technology correspondence table (old Area 4.2) should be updated to reference the new Soft Correspondence Tendency Table format with the 20-tier scale.

**Part 5 (Combat and Fight Law):** Any Technology Force Category references using old tier numbers should be updated to the new tier numbers per Area 8.2 of this Part.

**Part 7 (Fusion Law):** Integration model threshold tables that referenced technology tier numbers should be updated: old Tier 6 → new Tier 8; old Tier 7 → new Tier 11; old Tier 8 → new Tier 13, etc.

**Part 11 (Energy Resource Law):** CPM interface technology requirements referencing tier numbers should be updated per Area 6.4 of this Part (Core CPM requires Level 8 CI Technology, not Level 6 as in the old system).

**Part 12 (Energy Relics and Artifacts Law):** Technology-Relic Hybrid Class tier prerequisites should be updated per Area 6.3 of this Part (Class 3 requires Level 8 minimum, not Level 6 as in the old system).
