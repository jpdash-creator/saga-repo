## Area 18 — Advanced Technology-Cultivation Integration Reference

*Moved to Part 31 (Cultivation-Technology Synergy Law), Areas 5 and 12 as of v2.1.*

The full integration model deep reference (Model A through D from the technology-side perspective), integration model technology certification checklist, and Integrated Practitioner classification are now governed by Part 31. See:

- **Part 31, Area 5** — Integration models in depth: what each model produces, what each track gains, emergent capabilities at each model level
- **Part 31, Area 12** — Integrated Practitioner classification: definition, personal synergy assessment, the asymmetric Integrated Practitioner, social and factional position
- **Part 31, Area 19.2** — Common synergy scenarios including the step-by-step integration model certification check

**Technology-Side Quick Reference (retained):**
- Model A: CI Technology not required; pure parallel deployment
- Model B: CI Technology Level 3–5; CPM conversion efficiency 20–70%
- Model C: CI Technology Level 6–8; conversion efficiency 70–88%; Technology-Relic Class 3 achievable
- Model D: CI Technology Level 8–20; conversion efficiency 85–95%+; unified substrate

For complete governance: Part 31, Area 5.
