## Area 16 — Psychological States Taxonomy Reference

### 16.1 — Complete Psychological State List

The following states are canonical psychological states in the Starward Saga. Each character with significant narrative presence should have their current state in each relevant category tracked in their character record:

**Primary Psychological State (one active at a time):**

| State | Definition |
|-------|-----------|
| Grounded | Coherent, integrated, stable functioning — the optimal base state |
| Stressed | Active under pressure but managing; some functional degradation |
| Grieving | In active grief for a specific loss; varying functional impact by phase |
| Traumatized (Acute) | In acute phase of PIS-5+ trauma; significant functional impairment |
| Traumatized (Chronic) | Carrying unresolved PIS-5+ trauma that has stabilized into chronic state |
| Morally Injured | Carrying unresolved moral injury that creates identity incoherence |
| Obsessed | Organized around a compulsive focus (power, revenge, protection, etc.) |
| Isolated | Experiencing significant social isolation with psychological impact |
| Identity Fractured | Active identity crisis event |
| Cultivatingly Destabilized | Psychological state has direct cultivation-practice disruption |
| Hollow (Psychological Death) | Terminal state — psychological function ceased |

**Secondary Psychological States (multiple possible):**

| State | Definition |
|-------|-----------|
| Hypervigilant | Persistently elevated threat sensitivity |
| Dissociated | Periodic or persistent detachment from immediate experience |
| Suppressed | Active suppression of significant psychological material |
| Grief-Carrying | Carrying resolved or partially-resolved grief as part of permanent character |
| Heart-Dimmed | Cultivation Heart not accessible due to psychological configuration |
| Heart-Awakening | In a Heart awakening process triggered by psychological event |
| Soul-Contaminated | Carrying soul contamination with psychological manifestations |
| Morally Integrating | Actively working through moral injury toward resolution |
| Psychologically Growing | In a growth trajectory — an active resolution process is underway |
