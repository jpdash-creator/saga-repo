## Area 15 — Part 21 and the Synergy Civilization (Part 31 Interface)

### 15.1 — CCT as the Primary Synergy Gate

The CCT (CCT-1 through CCT-20) replaces the interim "Civ-1 through Civ-20" notation in Part 31. The Civilization Tier Synergy Access Table in Part 31, Area 2.1 is updated to reference CTDs:

| Designation (CCT) | Synergy Access (Part 31 Area 2.1) |
|---|---|
| Subsistence (CCT-1) | None — no institutional capacity |
| Formative (CCT-2) | Coordination synergy only |
| Industrial (CCT-3) | Basic augmentation — CPM as fuel beginning |
| Planetary (CCT-4) | Model A–B threshold achievable |
| Multi-World (CCT-5) | Model B fully operational |
| Solarian (CCT-6) | Expanded Model B |
| Stellar (CCT-7) | Model B–C transition |
| Interstellar (CCT-8) | Model C fully operational |
| Expansionary (CCT-9) | Expanded Model C |
| Clusteral (CCT-10) | Model C–D transition |
| Galactic (CCT-11) | Model D fully operational |
| Intergalactic (CCT-12) and above | Model D extended to civilization scale |

### 15.2 — SA Axis and Part 31

The SA axis value (Area 2.5) directly corresponds to Part 31 integration model access:
- SA-3 through SA-4 = Model A range
- SA-5 through SA-6 = Model B range
- SA-7 through SA-8 = Model C range
- SA-9 through SA-10 = Model D range

Part 31 governs what synergy outputs those models produce. Part 21 governs what SA value the civilization has achieved.

### 15.3 — Rule 2.1.3 Deference Resolution

Part 31, Rule 2.1.3 stated: "When Part 21 is authored, its civilization tier classification supersedes this Area's civilization tier reference." That deferral is now resolved. Part 21 CTDs are the canonical civilization tier reference. Part 31's synergy access table must use Civilization Tier Designations, not Civ-tier numbers or prior Hold Designation names.
