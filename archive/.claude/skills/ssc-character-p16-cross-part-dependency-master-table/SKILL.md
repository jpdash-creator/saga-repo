Part 16 also governs which ledger folder each character type routes to: heroes → ledger-character-hero; villains → ledger-character-villain; side characters → ledger-character-side (per Part 1 Area 5 Ledger Registry). Classification changes (rank promotion, realm breakthrough, integration type transition) are mandatory Post-Write Ledger Update (Part 1 Area 6.3) triggers.
