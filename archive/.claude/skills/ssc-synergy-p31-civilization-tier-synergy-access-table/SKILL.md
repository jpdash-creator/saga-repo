## Area 8 — Civilization Tier Synergy Access Table

This Area provides the comprehensive reference table mapping civilization tier to accessible synergy categories across all domains. It consolidates the civilization-tier gate principle from Area 2.1 with specific synergy category unlocks.

| CCT / CTD | TA Axis Range (Part 21) | EA Axis / CPM Grade Access (typical) | Integration Model | Key Synergy Unlocks |
|---|---|---|---|---|
| CCT-1 — Subsistence | TA 1–2 | EA 1–2 / Power Crystal (low) | None | No institutional synergy capacity |
| CCT-2 — Formative | TA 2–3 | EA 2–3 / Power Crystal | None | Basic coordination; cultivator physical work; natural CPM terrain selection |
| CCT-3 — Industrial | TA 3–4 | EA 3–4 / Power Crystal–Gem (low) | None–A | Early CPM use as technology supplementary fuel; soul-sense in research; early cultivation-informed materials |
| CCT-4 — Planetary | TA 4–5 | EA 4–5 / Power Crystal–Gem | A–B (early) | Model A–B threshold; CPM-powered devices; cultivation monitoring; early formation array + technology infrastructure |
| CCT-5 — Multi-World | TA 5–6 | EA 5–6 / Gem–Shard (low) | Model B | CPM industrial fuel; cultivation training chambers; Relic Class 1–2; Sacred Ground access transport; cultivation monitoring safety systems |
| CCT-6 — Solarian | TA 6–7 | EA 6–7 / Gem–Shard | Model B | Multi-world cultivation infrastructure; expanded CPM harvest; formation array networks at inner stellar scale |
| CCT-7 — Stellar | TA 7–8 | EA 7–8 / Shard | Model B–C | Emerging symbiotic capability; outer-system cultivation zones; early Relic Class 3; soul-sense research at stellar scale |
| CCT-8 — Interstellar | TA 8–9 | EA 8–9 / Shard–Core | Model C | Full symbiotic integration; Relic Class 3; high-fidelity CPM conversion; technology-enhanced Sacred Ground conditions; stellar cultivation zone enrichment |
| CCT-9 — Expansionary | TA 9–10 | EA 9–10 / Core (low) | Model C | Multi-stellar synergy infrastructure; AI cultivation path optimization; 72–80% CPM conversion across all affinity types |
| CCT-10 — Clusteral | TA 10–11 | EA 10–11 / Core | Model C–D | Advanced symbiotic; early unified integration at cluster scale; 80–88% conversion; lifespan synergy at civilizational deployment |
| CCT-11 — Galactic | TA 11–12 | EA 11–12 / Core–Divine Liquid | Model D | Full unified integration; galaxy-scale ambient qi enrichment; AI-scale cultivation optimization; 85–95% CPM conversion; emergent capabilities at galactic scale |
| CCT-12 to CCT-14 | TA 12–14 | EA 12–14 / Divine Liquid | Model D | Full Model D extended to civilization scale; energy substrate merging; all synergy categories at maximum depth |
| CCT-15+ (Apex) | TA 15–20 | EA 15–20 / Divine Liquid peak | Transcendent | Synergy beyond model classification — requires Part 28 narrative authorization (Part 21 Area 7) |

**Rule 8.1 — Synergy Access Is a Ceiling, Not a Floor:** The table specifies the maximum synergy accessible at each CTD tier. Civilizations may have lower actual synergy even at high CCT levels if they have not invested in integration infrastructure. A CCT-8 (Interstellar) civilization that has deliberately deprioritized CI Technology has the CCT to access Model C synergy but may have only Model A or B in practice. CCT gates the ceiling; investment determines actual position.

**Rule 8.2 — Synergy Access Requires CI Technology Domain Investment:** Integration model access requires CI Technology (Part 8 Domain 12) to be developed at the appropriate level. A CCT-8 (Interstellar) civilization with Level 3 CI Technology (underdeveloped) achieves only Model B synergy regardless of its overall technology tier. The CI Technology domain level is the direct synergy access determinant within the CCT range; the CTD is the prerequisite gate.
