## Area 8 — Weapon Construction Prerequisites

### 8.1 — Multi-Domain Construction Requirement

All weapons above Tier 4 require simultaneous satisfaction of multiple technology type domain prerequisites, not just the primary Type 8 Military domain. This multi-domain requirement reflects the fundamental law of P8-5.3 (The Fourteen-Domain Transfer Limitation).

| Weapon Tier | Required Domains (minimum levels) | Notes |
|---|---|---|
| Tier 1–2 | Type 8 Level 1–2 only | No multi-domain prerequisite |
| Tier 3–4 | Type 8 Level 3–4; Type 1 (Industrial) Level 3–4; Type 7 (Energy) Level 3–4 | Standard industrial weapons package |
| Tier 5 | Type 8 Level 5; Type 7 Level 5; Type 1 Level 5; Type 14 (Materials) Level 5; Type 2 (Information) Level 5 | Five-domain minimum for Tier 5+ |
| Tier 6–7 | Type 8 Level 6–7; Type 7 Level 6–7; Type 1 Level 6–7; Type 14 Level 6–7; Type 10 (Space) Level 6–7 | Orbital and vacuum operations prerequisite |
| Tier 8 | Type 8 Level 8; Type 7 Level 8; Type 10 Level 8; Type 14 Level 8; Type 12 (CI Tech) Level 8 | FTL weapon delivery systems require Type 10 Level 8 specifically |
| Tier 9–10 | Type 8 Level 9–10; Type 7 Level 9–10; Type 10 Level 9–10; Type 1 Level 9–10; Type 14 Level 9–10; Type 2 Level 9–10 | Multi-stellar weapon networks require Type 2 Level 9+ for targeting |
| Tier 11+ | Full Type 8 Level 11+ plus Type 7, 1, 14, 10, 2 all at Level 11+; increasingly exotic domains at higher tiers | Galactic-scale weapons require Type 11 (Cosmological) Level 11+ |

### 8.2 — Part 10 Military Science Prerequisites

The following thresholds from Part 10's Type 8 Military Science table are the critical science prerequisite gates for weapon construction tier advancement:

| Tier Gate | Part 10 Science Prerequisite | What It Unlocks |
|---|---|---|
| Tier 5 threshold | Type 8 Military Science: Level 5 | Directed energy weapons; orbital bombardment physics; autonomous targeting AI |
| Tier 8 threshold | Type 8 Military Science: Level 8 | Interstellar weapon delivery; planetary shielding; self-replicating weapons platforms; anti-cultivation targeting doctrine |
| Tier 11 threshold | Type 8 Military Science: Level 11 | Galaxy-topology weapons; stellar manipulation weapons; consciousness-targeting science |
| Tier 15 threshold | Type 8 Military Science: Level 15 | Cosmological weapons; spacetime weapon physics |
| Tier 20 threshold | Type 8 Military Science: Level 20 | Absolute weapons (deferred) |

### 8.3 — Prototype Weapon Governance

Weapons under development that have achieved construction above the civilization's current Technology Ceiling are classified as Prototype weapons. Prototype governance follows Part 9, Area 4.1.1 prototype rules:

1. Prototype weapons may be constructed but cannot be reproduced at scale without ceiling advancement.
2. Prototype deployment in combat is permitted with faction authorization but classified as an E5 escalation event regardless of actual WS class due to technology demonstration risk.
3. Prototype weapons that fail catastrophically during deployment follow Part 11 terrain hazard rules for uncontrolled energy release.
