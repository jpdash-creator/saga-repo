## Area 19 — Author Quick Reference

### 19.1 — Five Questions Before Writing Synergy

Before writing any cultivation-technology synergy event, answer these five questions:

**Question 1: What civilization tier is the civilization?**
This determines the maximum integration model accessible (Area 8) and whether the synergy category claimed is institutionally available.

**Question 2: What CPM grade is available?**
This determines the cultivation-side energy depth for the synergy event (Area 9.1). Match CPM grade to CI Technology level.

**Question 3: What is the CI Technology level?**
This determines the technology-side integration model access (Part 8, Area 6.2) and the CPM grade it can safely handle (Part 8, Area 6.4).

**Question 4: What integration model is claimed?**
Verify technology-side threshold (Part 8, Area 6.2) and cultivation-side threshold (Part 7, Area 6.2) are both met. Effective model = lower of the two.

**Question 5: Is there a Sacred Ground or location factor?**
Determine if the location amplifies synergy (Area 10) or provides the Sacred Ground Synergy Step-Up Effect (Area 2.3).

If all five pass: the synergy claim is consistent with Part 31 governance.

### 19.2 — Common Synergy Scenarios

**Scenario 1: CPM-Powered Weapons System (Model B)**
A Tier 6 civilization with Level 5 CI Technology feeds Gem CPM (Grade 8) into a military system. Assessment: Gem Grade 8 minimum is Level 4 CI Tech (✓ Level 5 meets it); affinity preservation requires Level 5 (✓ exactly meets it — affinity preserved); integration model for Tier 6 / Level 5 CI Tech = Model B (✓ consistent). Synergy output: affinity-typed military system output at augmentative level; cultivation practitioners with matching affinity have the Affinity Advantage against opposing-affinity targets.

**Scenario 2: Technology Cultivation Chamber (Model B environment support)**
CCT-5 (Multi-World) civilization with Level 5 CI Technology provides cultivation chambers. Assessment: CCT-5 can access full Model B (✓); Level 5 Energy Technology supports cultivation chambers at +15–25% ambient qi (✓). This is correct and requires no further validation.

**Scenario 3: Technology-Relic Class 3 Hybrid (Model C)**
Core Formation realm practitioner + Level 8 CI Technology + Core CPM (Grade 15). Assessment: Cultivation side = Core Formation, minimum for Class 3 hybrid operation per Part 7 (✓); Technology side = Level 8 CI Tech for Core CPM (✓) and Class 3 hybrid construction (✓); Model C threshold both sides (✓). Synergy output: Model C symbiotic integration; Class 3 hybrid achieving outputs neither technology nor relic alone produces.

**Scenario 4: Claiming Model D in CCT-5 Civilization**
Assessment: CCT-5 (Multi-World) maximum integration model = Model B (Area 8 table). Model D is not accessible at CCT-5 regardless of individual cultivator realm or personal CI Technology access. This claim requires Part 28 authorization or civilization tier correction per Part 21 CTD Minimum Thresholds.

### 19.3 — Synergy Narrative Checklist

For extended synergy sequences (battles, civilization-scale synergy events, Integrated Practitioner character arcs), the following checklist ensures consistency:

☐ Civilization tier established for each civilization involved  
☐ CPM grade available established  
☐ CI Technology level established  
☐ Integration model for each practitioner or system identified  
☐ Sacred Ground or location factors established if applicable  
☐ Synergy outputs described as categorically new (not merely additive) at Model C/D  
☐ Track independence maintained — neither track fails because the other is present  
☐ Part 3 realm ceiling not exceeded on cultivation side  
☐ Part 8 Technology Ceiling not exceeded on technology side  
☐ Part 5 is the adjudication authority for all combat outcomes
