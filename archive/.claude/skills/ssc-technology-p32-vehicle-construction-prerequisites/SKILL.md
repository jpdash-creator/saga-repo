## Area 9 — Vehicle Construction Prerequisites

### 9.1 — Construction Tier Minimum Requirements

Vehicle construction requires simultaneous satisfaction of prerequisites across multiple Part 8 Technology Type Domains. The following table establishes the minimum multi-domain prerequisite for constructing each vehicle tier class.

| Vehicle Tier | Primary Domain (Type 9) Level | Secondary Domain Minimums | Energy Domain (Type 7) | Materials Domain (Type 14) | AI Domain (Type 4) |
|---|---|---|---|---|---|
| Tier 1 vehicles | Type 9: Level 1 | None required | None | None | None |
| Tier 2 vehicles | Type 9: Level 2 | Industrial (Type 1): Level 2 | Type 7: Level 1 | Type 14: Level 1 | None |
| Tier 3 vehicles | Type 9: Level 3 | Industrial: Level 3; Engineering (Type 6): Level 2 | Type 7: Level 2 | Type 14: Level 2 | None |
| Tier 4 vehicles | Type 9: Level 4 | Industrial: Level 4; Engineering: Level 3; Information (Type 2): Level 3 | Type 7: Level 3 | Type 14: Level 3 | Type 4: Level 2 |
| Tier 5 vehicles | Type 9: Level 5 | Engineering: Level 4; Energy: Level 4; Medical (Type 5): Level 3 | Type 7: Level 4 | Type 14: Level 4 | Type 4: Level 3 |
| Tier 6–7 vehicles | Type 9: Level 6–7 | Engineering: Level 5+; Space (Type 10): Level 5+ | Type 7: Level 5–6 | Type 14: Level 5 | Type 4: Level 4 |
| Tier 8 vehicles | Type 9: Level 8 | All domains: Level 6+ average; Space: Level 7+ | Type 7: Level 7 | Type 14: Level 7 | Type 4: Level 6 |
| Tier 9–10 vehicles | Type 9: Level 9–10 | All domains: Level 7–8+ | Type 7: Level 8+ | Type 14: Level 8+ | Type 4: Level 7+ |
| Tier 11–14 vehicles | Type 9: Level 11–14 | All domains: Level 10–12+ | Type 7: Level 10+ | Type 14: Level 11+ | Type 4: Level 10+ |

**Rule 9.1.1 — No Domain Short-Cutting:** A civilization with Type 9 Level 10 but Type 14 (Materials) Level 6 cannot construct Tier 10 FTL vessels. The materials science prerequisites for hull construction at that tier are not satisfied. All listed prerequisites must be simultaneously met.

**Rule 9.1.2 — Scale Class Construction Multiplier:** Higher Scale Class vehicles require proportionally higher domain levels. A SC-VII (Civilization Scale) vessel requires domain levels 2–3 tiers above the basic tier prerequisite shown in the table.

### 9.2 — CHV Construction Prerequisites

Cultivation-Hybrid Vehicles require additional prerequisites beyond standard technology construction:

| CHV Class | Additional Prerequisites |
|---|---|
| CHV-A | Xiantian-realm formation inscriptor on construction team; Part 12 Tier 1–2 formation array construction capability |
| CHV-B | Core Realm formation inscriptor; Part 12 Tier 2–3 capability; CPM supply chain of Shard grade minimum (Part 11) |
| CHV-C | Core Realm soul cultivation specialist; CI Technology (Type 12) Level 7+ (Part 8); Part 4 soul technique integration expertise |
| CHV-D | Heaven Treading+ inscriptor for formation primary systems; CI Technology Level 10+; Part 31 Model C synergy civilization prerequisite |
| CHV-E | Divine Sea Realm inscriptor; Part 12 Tier 4 formation arrays; Divine Liquid access (Part 11, EA-14+); Part 31 Model D |
