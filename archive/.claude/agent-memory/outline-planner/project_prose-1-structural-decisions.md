## Current container names (Area 1)

- Novel-Part 1 — *The Kingdom That Wakes in Pairs* — **kept**. "Wakes in Pairs" encodes the
  Twin Oath / Paired Legitimacy doctrine, which is the kingdom's actual constitutional
  mechanic, not just imagery.
- Chapter 1 — *The Hour Before the Courts Open* — **kept**. "The Courts" is the in-world
  Sword Court / Signet Court pair (lore exists), and the name now spans both Prose units
  better than it did when the Chapter held only one.
- Area 1 — *The Capital Before the Bells* — **changed** from *The Platform Before the Bells*.
  Reason: the Area now contains a road-approach to the capital as well as the palace scene,
  and "the Platform" names a west-edge palace platform that Prose 1 never enters. An Area
  name that names a location one of its Prose never visits misleads the Prose Maker and
  breaks Rule 18.4.3 coherence. "Capital" spans both; "the Bells" (the canonical paired
  brass/alloy morning toll) is the device that unifies the two units into one dawn.

## Structure

Area 1 holds **two** Prose: a wide establishing approach-to-the-capital (new non-royal POV),
then a tight Varys-POV palace scene. The wide-then-narrow order is a user decision, not
mine. Varys keeps POV on the royal unit because the west-edge platform practice and the
Sapphire Line dawn load-transition observation are both canonically *his* — rendering them
from Valia's POV would make them second-hand. Valia's first POV prose stays available as a
distinct later milestone, which is an owed structural beat.

**How to apply:** Inherit Novel-Part / Chapter / Area names unchanged for every later Prose
in the same containers; only the Prose name is freshly authored each time. Related:
[[ledger-reset-contamination]], [[feedback-opening-scene-rejection]].
