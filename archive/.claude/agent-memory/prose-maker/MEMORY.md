# Prose Maker — Working Notes

Private, self-maintained notes for the prose-maker agent only (not shared canon — that lives
in `.claude/story-memory/`). Use this file to record recurring voice/style patterns,
mistakes to avoid repeating, and canon nuances that took extra effort to get right, so they
don't need to be rediscovered each session.

## Drafting rules learned the hard way
- [Dialogue italics](feedback_dialogue-italics-gate1-fail.md) — all speech is `*"words"*`, double quotes AND italics; plain quotes = Gate 1 FAIL.
- [Age arithmetic](feedback_age-arithmetic-must-be-computed.md) — check every "in N years she will be X" against the ledger's Locked Canon start age.

## Workflow
- [Revisions need the draft inline](project_revision-tasks-need-full-draft-text.md) — pre-Gate-2 prose lives only in the caller's context, never on disk.
