**Word count (no shell).** Main recipe: Grep the Area file with `\S+(?:\s+\S+){19}|\S+(?:\s+\S+){0,18}\s*$`, output_mode content, `-o`, `-n`, `head_limit` 0. Each line is a 20-token run, except the last of a paragraph (a 1 to 19 token tail; an exact multiple of 20 has no tail line, so count each paragraph's last line by hand). Total = 20 x runs + tails; ignore file lines 1 to 4 (title, reference, date line). Cross-check by summing runs and tails per paragraph.
- Exact whole-token count as the chapter builder does it (narrative lines start with a letter or `*"`): Grep `count` mode with `^(?:[A-Za-z]|\*")[^ ]*(?: [^ ]+){20j-1}` for j = 1, 2, ... until empty gives R (sum of counts); remainders r = 1..19 with `^(?:[A-Za-z]|\*")[^ ]*(?: [^ ]+){r-1}(?:(?: [^ ]+){20})*$` (r = 1 drop the group; r = 0 use `{19}`); the counts C_r must sum to the paragraph count; total = 20R + sum(r x C_r). Run all searches in one parallel message. `count` mode counts lines, never matches.
- Pre-check the file: no CRLF (`\r$`), no double space, tab or trailing space on narrative lines, no standalone dash, ellipsis or asterisk tokens.
- Output over about 30KB is saved to a tool-results file; Read it in full.

**Voice and Variety greps.** Whole-word `-o -n -i` over the Chapter's `area-0*.md` (tally by file and line); one Grep with a hand-picked feeling-word list; mean sentence length by hand count of sentence-ending marks per paragraph (semicolon clauses one, speech included), words divided by sentences.

**Paths and gotchas.**
- Part 35 skill by exact path `.claude/skills/narration-content-density-law/SKILL.md` (Glob finds nothing).
- Chapter Specs: `.claude/story-memory/phase-section-part-chapter-area-specs/phase-N/section-M/part-P/chapter-NNN-spec.md`; Read in pages of 170 lines or fewer (25,000-token cap); Audit and Settlement Notes are near the end. The Novel-Part Spec closing-state block is its section 8 (Grep `^## `). For a previous Area's opening and closing types read that written Area's first and last paragraphs, not an earlier Chapter spec.
- Grep `glob: chapter-00*/area-0*.md` returns nothing; use `glob: **/area-0*.md` with the Novel-Part folder as `path`, or `area-0[123].md` with one Chapter folder.
- Grep without `-o` prints "[Omitted long matching line]" for long paragraphs; use `-o` with a short pattern, or Read the range.
- Tracker (`cdl2-density-tracking/phase-N/section-M-aggregate.md`): Read once, then chain single-line Edits (anchors unique per row); about 30 single-line Edits can run in parallel batches on a revision; a multi-line old_string matches (LF). Re-Read if another worker changed the file. Recompute unrounded aggregates by long multiplication. "Before" figures come from the tracker row, never `_archive`.

**Per-paragraph and per-block tallies (whole-built Chapter; learned 2026-10-18 at Chapter 004).** After the layer and remainder counts give the total, Grep the Chapter with `\S+(?:\s+\S+){19}|\S+(?:\s+\S+){0,18}\s*$` (`-o -n`, `head_limit` 0): about 640 rows, 59 KB, saved to a tool-results file; Read it in two pages of 330 rows. Per paragraph: 20 x the run rows + the tail row (count its tokens by eye, at most 19; no tail row means an exact multiple of 20). Sum per block between the hidden `<!-- AREA NN -->` line numbers (find them with `<!-- AREA \d+ -->` and `-n`). Verify: tally the tails by length and compare with the twenty remainder-class counts (this caught one 5-token tail read as 4); the block sums must equal the count-mode total. Layer searches with `{279}` compile fine.
- Glob gotcha: the tool splits `glob` on spaces, so `{Chapter 001*.md,...}` fails. Use `?` for the space (`Chapter?00[23]*.md`) or `**/*.md` with the Novel-Part folder as `path` (it holds `chapter-001/area-0N.md`, the Chapter `.md` files and `.docx` twins, and no `_archive`).
- Voice and Variety greps used: gesture counts by whole-word `-o -n` (tapp, count, lean, cord, nick, `door end`); simile guide post `\blike (?:a|an|the|someone)\b|\bas (?:if|though|from)\b` (false hit: "would like the order"); earlier-Area hits by `**/*.md` over the Novel-Part folder with `-o -n` (add `.{0,90}` either side to see context for long lines); the previous Chapter's closer by Reading its last lines.
