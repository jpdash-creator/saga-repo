**Word count (no shell).** Main recipe: Grep the Area file with `\S+(?:\s+\S+){19}|\S+(?:\s+\S+){0,18}\s*$`, output_mode content, `-o`, `-n`, `head_limit` 0. Each line is a 20-token run, except the last of a paragraph (a 1 to 19 token tail; an exact multiple of 20 has no tail line, so count each paragraph's last line by hand). Total = 20 x runs + tails; ignore file lines 1 to 4 (title, reference, date line). Cross-check by summing runs and tails per paragraph.
- Exact whole-token count as the chapter builder does it (narrative lines start with a letter or `*"`): Grep `count` mode with `^(?:[A-Za-z]|\*")[^ ]*(?: [^ ]+){20j-1}` for j = 1, 2, ... until empty gives R (sum of counts); remainders r = 1..19 with `^(?:[A-Za-z]|\*")[^ ]*(?: [^ ]+){r-1}(?:(?: [^ ]+){20})*$` (r = 1 drop the group; r = 0 use `{19}`); the counts C_r must sum to the paragraph count; total = 20R + sum(r x C_r). Run all searches in one parallel message. `count` mode counts lines, never matches.
- Pre-check the file: no CRLF (`\r$`), no double space, tab or trailing space on narrative lines, no standalone dash, ellipsis or asterisk tokens.
- Output over about 30KB is saved to a tool-results file; Read it in full.

**Voice and Variety greps.** Whole-word `-o -n -i` over the Chapter's `area-0*.md` (tally by file and line); one Grep with a hand-picked feeling-word list; mean sentence length by hand count of sentence-ending marks per paragraph (semicolon clauses one, speech included), words divided by sentences.

**Per-paragraph and per-block tallies (whole-built Chapter; learned 2026-10-18 at Chapter 004).** After the layer and remainder counts give the total, Grep the Chapter with `\S+(?:\s+\S+){19}|\S+(?:\s+\S+){0,18}\s*$` (`-o -n`, `head_limit` 0): about 640 rows, 59 KB, saved to a tool-results file; Read it in two pages of 330 rows. Per paragraph: 20 x the run rows + the tail row (count its tokens by eye, at most 19; no tail row means an exact multiple of 20). Sum per block between the hidden `<!-- AREA NN -->` line numbers (find them with `<!-- AREA \d+ -->` and `-n`). Verify: tally the tails by length and compare with the twenty remainder-class counts (this caught one 5-token tail read as 4); the block sums must equal the count-mode total. Layer searches with `{279}` compile fine.
- Glob gotcha: the tool splits `glob` on spaces, so `{Chapter 001*.md,...}` fails. Use `?` for the space (`Chapter?00[23]*.md`) or `**/*.md` with the Novel-Part folder as `path` (it holds `chapter-001/area-0N.md`, the Chapter `.md` files and `.docx` twins, and no `_archive`).
- Voice and Variety greps used: gesture counts by whole-word `-o -n` (tapp, count, lean, cord, nick, `door end`); simile guide post `\blike (?:a|an|the|someone)\b|\bas (?:if|though|from)\b` (false hit: "would like the order"); earlier-Area hits by `**/*.md` over the Novel-Part folder with `-o -n` (add `.{0,90}` either side to see context for long lines); the previous Chapter's closer by Reading its last lines.

**Learned 2026-10-19 at Chapter 005 (whole-built, 11,534 words, 102 paragraphs).**
- Narrative paragraphs can open on a corner-bracket letter mark (`「`), so the first-character class is `(?:[A-Za-z]|\*"|「)`; check that `count` of `^(?:[A-Za-z]|\*"|「)` equals the paragraph count (102 here) and that non-empty lines = paragraphs + headings + `---` + markers + date lines + `* * *`.
- Exact per-paragraph tallies with no row-reading: run the layer searches (`{19}`, `{39}` ... until empty; sixteen here) in `content` mode with `-n`, no `-o` (long lines print "[Omitted long matching line]", short ones in full), plus the twenty remainder searches in `content` mode. A paragraph's tokens = 20 x (number of layers whose list holds its line) + its remainder class. Sum per Area block between the marker line numbers; check R x 20 + sum(r x count) against the block sum. About 35 Greps in two parallel batches, small output.
- Earlier-Area hits: `glob: Chapter?00[234]*.md` with the Novel-Part folder as `path` works; `path` = the `chapter-001` folder covers the Chapter 001 Area files. A brace glob like `{chapter-001/*.md,Chapter?00[234]*.md}` returns "No matches found" silently, a false negative: always test a search against a known hit first (here "how long yet" in Chapter 004).
- Marker line numbers map a hit to its Area block (Grep `<!-- AREA \d+ -->` with `-n` in each earlier Chapter). Reference form used for hits: `1.1.1.003 A06, line 284`.
- Parallel Edits on the tracker (about 35 in four groups) did not clobber each other; confirm afterwards with a `count` Grep on the new strings and a row-start Grep, not a full re-Read.
- A Chapter Spec of this size (863 lines) is read in pages of about 60 lines (lines are very long); the Area blocks run from about line 159 to 661 and the Audit and Settlement Notes from 671 to the end.

**Learned 2026-10-20 at Chapter 006 (whole-built, 13,085 words, 133 paragraphs, seven blocks; Chapter Spec 976 lines, read in pages of 60).**
- Cheaper per-paragraph tally: the layer searches for j = 1 to 3 (at least 20, 40, 60 tokens) print 20 to 25 KB each and get saved to files; skip reading them. Instead list the short paragraphs by length class (`{0,18}$`, `{19,38}$`, `{39,58}$`, `{59,78}$` after the first-token group) in content mode (short lines print in full), run layers j >= 4 in content mode (line numbers only), and the twenty remainder searches. Layers of a paragraph = 0, 1, 2, 3 by class, else 3 + the number of j >= 4 lists holding its line. Check: sum of assigned layers must equal R; a mismatch of 2 meant two paragraphs misfiled by a length class (an 18-token and a 45-token line). Then 20 x layers + remainder per paragraph, summed per block between the marker lines.
- Two Novel-element names missing from my map above are also "not scored here": Mystery/clues/suspense and Villains' presence (Part 36 Area 15.5 rows 10 and 23 carry no scorer entry). Rows that do map: Fights (Combat, Named Moves), Injury/recovery (Combat), Setting description (Lore, Travel), Friendship/rivalry and Relationships (Dialogue), Moral choice (Character Development), Reveals/secrets (Information), Technology/engineering (Technology), Politics (Political, Information).
