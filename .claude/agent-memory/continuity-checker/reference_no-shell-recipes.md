**Cell counts and identity.** `^\| Name \|([^|]*\|){N}$` (end with `\r?$` in CRLF files). Cells: side Tier D 10, Tier C side 8, villain Tier C 9, Tier B 12, Tier A 11, status registry 7, pending 4, compliance 3 to 5 by tier, location registry 12, named items 10, calendar Area rows 4, Owed Beats 3, Section 10 row 4, Deferred 7. Code identity: one Grep per code (escape `\[SIG\]`, `\[AI\]`) with `path` `.claude` and a glob of the hand-off file plus `_index.md`, count mode; one hit in each proves identical; one structural regex per file proves token counts. Residue after a Chapter write: `1\.1\.1\.CCC\.\d` over story-memory with `!{**/_archive/**,**/session-log/**}`, then triage history versus live.

**Exact counts.** Token total: `\A[^ \n]+(?:[ \n]+[^ \n]+){N-1}`; per block: `<!-- AREA 01 -->[ \n]+(?:[^ \n]+[ \n]+){K-1}[^ \n]+[ \n]+<!-- AREA 02 -->`; after a marker to the end: `<!-- AREA 0N -->(?:[ \n\r\t]+[^ \n\r\t]+){T}[ \n\r\t]*\z`. ASCII classes keep the regex small (worked to 5,437 tokens; Unicode `\S` hits size limits). Probe N and N+1; confirm the final value with a single-value query. Narration characters as `measure` counts them (asterisks and line breaks removed, date line and `---` out): `\*<date line>\*(?:[*\n]*[^*\n]){lo,hi}[*\n]*\z`, minus 3 per `---` line in a condensed file. When the coordinator sends the script's `measure` figures, verify instead of discover: per Area block two probes, `<!-- AREA NN -->(?:[ \n]+[^ \n<][^ \n]*){N}` true and N+1 false, on the written and the staged file (N = words + 3 per `* * *` + 1 per `---` + 6 per date line inside the block); `(^|\s)[^\w\s]+(\s|$)` lists punctuation-only tokens (all must sit in the title block, markers and breaks); `[^\x00-\x7F]` lists non-ASCII; `[^*]"[^*]` must return nothing (every quote sits against an asterisk).

**Byte-exact identity.** Multiline count-mode Grep of date line + `\n\n` + all paragraphs joined by `\n\n` (escape `. * ?`), run on the scratchpad control and on the written .md; copy the pattern from the control view; both returning 1 proves identity. Hygiene Greps: `\r`, `[—–“”‘’…]` in the body, `[ \t]+$|\t`, contraction regex, forbidden vocabulary, `\blevels?\b`. Staged versus written: the written file adds the header block, so token totals differ by exactly its size. Whole-built Chapter at Gate 2: the script also puts a blank line after a marker that the staged text glues to the date line or a break, so run one pattern per Area block (about 12K characters works), starting at the date line or at `---\n\n` and ending at the next `<!-- AREA NN -->` marker (the last block at `\n?\z`), on the staged copy and on the written .md (two Greps per block, count 1 each proves identity). Faster, one typed pattern for staged, written and archived files together: Grep with `path` the repo root, `multiline`, count mode and `glob` `{.claude/temp/X.md,projects/.../X.md,projects/.../_archive/<stamp>/.../X.md}` (cwd-relative paths; the glob is split on spaces, so write each space as `?`; a glob overrides the hidden-folder rule, so `.claude/temp` is searched; name only exact files). Pieces of 7K to 8K characters (the Windows command line caps near 32K), each starting with the last sentence of the piece before it, `\n\n` between paragraphs, `\.` `\*` `\?` escaped, the last piece ending `\n?\z`; every piece must return count 1 for all three files. For a cut clause put `(?:, as ...)?` in its piece, then one count Grep of the clause shows which file holds it.

**The .docx.** Read refuses it. Grep with the explicit file path and `-o 'word/[A-Za-z0-9_./-]{3,40}|\[Content_Types\]\.xml'` lists zip entries (proves a real package); text parity rests on the orchestrator's python-docx read-back (ask for it in the first progress message; say it was not re-run). Paragraph count of a whole-built Chapter with no Title Page: 7 header paragraphs (phase icon, STARWARD SAGA, PHASE, SECTION, PART, blank, Chapter) + narration paragraphs + date lines + one per `---` (rendered `*   *   *`) + one per `* * *` (rendered as the asterism); it matched the lead's 154 for Chapter 004. Cross-check a relayed read-back with it: a break's 0-based index = 7 + date lines + narration paragraphs + marks before it.

**Gate 2 audit lane.** Block A and B sources: Part 2 Rules 8.2.1, 9.10.1, 9.10.2, 9.13.2 (Areas from the Chapter Spec, Chapters from the Novel-Part Spec, Parts from the Section Spec, Sections from Part 30; Block B reads `undeclared`, "plan list is the guide"). File-pair checklist: Part 2 Rule 6.3.4a. After `/revise-area` the condensed Chapter pair is stale: report a notice. For the Part 2 Rule 5.3.2a archive-listing conflict use one Glob of the named timestamped folder and disclose it. Standalone reconcile: Coverage cells of Novel-Part and Section registry rows are owed at `/next-chapter`; registry header dates can lag (fix the touched ones, report the rest).

**Edit techniques.** Huge ledger line: Read offset N limit 1, then Edit on a short unique anchor (Grep count first). A multi-line old_string works in CRLF files. Edit one row per file in parallel, serial within a file. skill-index `line_count` is approximate.

**Read page size.** One Read call is capped near 25,000 tokens whatever `allow_large` says. Read labels: offset 0 labels the first line 0 (label = Grep line minus 1), while offset N above 0 starts at line N and labels it N, so chunks read at offsets 0 and 150 overlap by one line and nothing is missed; Grep line numbers are 1-based. The hero ledgers (about 1,100 dense lines each) read at 90 to 110 lines a call (a 150- or 230-line call fails); a spec file reads at about 100 to 190 lines. Map a big file first with Grep `^#{1,3} ` (count mode gives its length), then page it. `skill-index.json` is 14,000 lines: Grep `"skill_id"` with `-n` for each Part's block offset, then Read one block; Area titles sit at four-space indent (`^    "title"`).

**Part 39 catalog codes and register tallies.** Appendix B of `character-behavioral-synthesis-law` lists dimensions and option counts only. To prove a code exists and read its option text in one call, Grep the skill with one alternation: `^\| \`B39-(L02-(LEAD-09|FIRST-03)|L07-(MODE-01))\` \|` with `-n` (every hit is a real code; a missing code is absent from the output). A line the catalog cannot word takes the `-99` AUTHOR-SPECIFIED slot, which exists on every dimension (the immutable core uses `B39-L31-IMMUTABLE-99` when the two Signatures are outside its ten options, as `corin-vale` does). The 291 tally is proved by Grep count mode on the file: `^- \`B39-Lnn-[A-Z0-9]+(-nn)?\`.*\`\[ASKED\]\`` (and `[DERIVED]`), plus the sum of the open-mnemonic counts per Layer; ASKED + DERIVED + N-A + OPEN must equal 291. A Tier B file is modelled on `max-pryce.md` (compact, interview shape) for Sections 1 to 14 and on `wulfric-rask.md` for the evidence-line style. The interview packet and its author answers are in the session `.jsonl` when the brief only summarises them (Grep a unique phrase across `~/.claude/projects/<repo>/*.jsonl` and `subagents/`, then Read that one line; it can be 10K tokens).

**Memory path.** Write memory only to the repo-root `.claude/agent-memory/continuity-checker/`. The paths the prompt names (`.../part-1/.claude/agent-memory/...`, `.claude/.claude/agent-memory/...`) are wrong and make stray folders.
