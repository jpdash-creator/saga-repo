Chapter-specific facts live in the specs, ledgers and session-log. Re-verify against the files.

**No shell.** `manual_ledger_query.py validate` cannot be run; predict it and ask the command to run it when a Manual Ledger cell changed. A script change goes to the author first (Part 42 Rule 42.14.1.4).

**References.** Whole-built Chapter: Chapter ref only (`P.S.N.CCC`); cell form `Chapter NNN — <Title> (Ref: P.S.N.CCC)` with an EM DASH (Grep the existing form first; a hand-off hyphen is shorthand); prose says "Area block NN"; calendar rows per date segment (`P.S.N.CCC (date segment N)`, flashback rows left out of rollups, dates `Y.M.D / PD N`). Area-built: `(Ref: ...)` or `(Area <ref>)` at clause end, never nested, never "(Area 03 ..." digits only; header anchor fields hold only `Area NN — Title (Ref: ...)`. After writing Grep `1\.1\.1\.CCC\.\d` and `\(Area 0\d`. `reset_story.py`: AREA_REF needs five parts (Chapter-only refs are not reset; known gap); it resets "First Area Appearance" columns by header when the cell count equals the header's; its CSV `first_area` step skips `cultivation/`; keep non-table notes out of the calendar Current Position block.

**Write only what the page says.** Check every trade, look, hour, count, quote and Signature code against the written .md (Grep); plan words stay in the spec (descriptor ROLE words are code tokens, say so). Never join two sentences into one quotation; count from the text (squads) and from codes, not memory; conformance by absence is not firing; do not widen a ruling; do not claim a re-audit that did not happen; an identity unnamed in the scene is recorded as taken to be the named person, with the reason; status `Dead` only where the prose establishes it.

**Rulings arrive by relay, in stages.** Write nothing the author has not ruled; a later message can correct or lift a hold (use the last one). A ruling reaches only the items it names; the others stay unruled with no Deferred row. Tier B, C, D are the checker's under Part 43 and may be written at once with reasons. Look for a relayed ruling on disk (spec notes) and cite it so lanes agree.

**Append-only.** Section 12 and Section 14 are append-only, also on an in-place revision: a correction is a new `CHANGE (correction of record)` entry; a DEFER again is a fresh Deferred row (7 cells; create the table if absent); entry numbers continue across a redraft and follow the orchestrator's naming. [EVOLVE] additive: add the clause, a dated ruling bullet and an italic Section 12 note (Drift Count 0, no log row, nothing superseded); the first EVOLVE on a file creates Section 14 (template ledger-schema-law Area 2.1) with a "see Evolution Entry N" pointer on the touched Layer line. [KEEP PROFILE] closes the pending row; mixed rulings sit in one Deferred row's Evidence cell. Classification changes: amend the sentences that use it as a determinant, leave baseline rows as history and add a dated classification note.

**First appearance.** A hero sets First Area Appearance and First On-Page Appearance only when present on the page. Owed Beats are opened per file by code Grep (UNSEEN, WEIGHT, COST for all; MASK only if a public-private divergence is registered; MECH-10 and SEAM-01 as registered); a line reads `Shown in P.S.N.CCC` when the page shows the beat (Rule 39.41.5.2: the Gate 2 of the Area that shows it writes the reference; the Chapter Spec decides when the story shows it and no beat is added to clear a line), with the page lines and the reason in an italic 11.3a note after the table; the oath-at-cost line stays OPEN when no promise or cost is on the page. A Gate 1 ruling that revises the page (a pause removed for a register break): Section 12 italic note with the ruling as relayed (no Deferred row, no Evolution Entry), the Section 10 row says the Signature "is not fired" and the break "is shown". The hero `_index.md` is edited by several lanes at once (the Edit reply says so): re-Grep the live row before each Edit; one lane owns the shared footnote. Hero Depth Test cell in the hero-index compliance registry at the first scene. Flagged Section 1 items become pending rows. Narrative summary mandate (Part 28 Area 17.4). A new named, described place triggers Threshold L-1 (file, registry row with Parent, compliance row, position rows, parent subsection); a room or feature of an existing building, or a descriptor road, ford or hut, is a section or pointer row (counted in Total Entries and said in the header); a proper-named bridge or road meets the travel-ledger threshold, descriptors do not; a new kingdom is Threshold L-2. A location stub's Collective Behavior Code stays OPEN-AUTHOR until two or more named characters are placed there. Tier D rows: people only spoken of say so; update both header counts and add a paragraph naming new rows; kept rows after a redraft get `pending redraft` cells. Do not print an author-removed concept's name.

**Row patterns.** Manual-borne Named Move: classification `Lineage or school technique`; Entity File = CSV path + move ID + manual ID + "the Manual Ledger owns every value"; Users: Tier C/D to the index registry, Tier B to the character file (a Manual Kit pointer line, no move block, Rule 42.12.4.3), unnamed fighters to the faction file; Naming Checks = `manual ledger <ID>; collision scan by ID and by name <date>; register <...>; move-naming law Rule 42.12.2.3 <date>`; a returning move or item gets a notes paragraph, not an edited row; a manual title on the page needs a named-items pointer row. A whole-built `first_area` takes the Chapter form (the validator pattern accepts only `Area N` or `Not yet established`; expect one C-16 per cell; fix proposed to the author). The cultivation-axis kit line is separate from the weapon `character-kits.csv` line. A new Tier B person's `characters.csv` and `character-kits.csv` rows (Rule 42.11.8.1) are written only from what the ledger supports: when `source`, `learned_via`, `mastery` or the affinity type are OPEN-AUTHOR, flag the rows as owed (Rule 42.11.4.1 bars going beyond the ledger) and write none; Tier B people registered after 2026-10-05 carry no rows, so check the CSVs before promising one. Varya (VRY) and Aegon (AEG) never carry a kit row (Part 42 Rule 42.11.7.1; the validator fails one as C-20): children who drill a Common primer at the rack are floor practice, so write their Manual Kit line as `none` with the learning-plan pointer plus a floor-practice clause, keep the moves' Users cells, and do not read the rule's last sentence as a licence for a row (a first write of such rows was withdrawn on 2026-10-21 by a correction of record). A spec sync's Signatures-fired flip is cheapest as one multi-line Edit per Area table (copy the rows from the Read), then Grep the count of `\| 1\.1\.1\.CCC \|$` against the planned rows. Level facts (Rule 29.12.1.3): hero Section 2 blockquote, Section 13, Section 10 rows, Section 9; Tier D a `Qi:` clause in the Current Condition body. Collision scans: Grep every name with `-i` over story-memory, count mode.

**Lanes and hazards.** Lanes write in parallel: inventory by a date Grep first, spot-check what exists, say what was already there. Trust the written file over the brief and report the difference. The index lane owns the INDEX-ROW cells of Tier A/B people; entity files belong to another lane (heads-up to main first). Re-Grep rows and counts just before each Edit on a shared index; anchor on unique substrings with the changing numbers; one Edit at a time per file; the 8-column separator is a substring of the 9-column one, so anchor on the header row; if a multi-line Edit fails, re-Read the live line. Glob lists oldest first. Never send a placeholder new_string. After a redraft, kept place files may carry archived-build facts: compare each non-author block with the written text, keep author lines, say text was replaced. Stale-quote hunt: Grep story-memory (glob `!**/session-log/**`) for the old phrases. Report differences between page and baseline; do not edit them.

**Pre-draft author-directed ledger step (before `/create-chapter` drafts).** Mark every amended spot `Author ruling, <date>` and keep the old wording only as a dated history note (summarise the dropped text rather than quoting it, so stale-phrase Greps stay clean). A ruling that changes a class or office (a head of a class, a second office) reaches mirrors: Grep the stale tokens over story-memory with `!**/{_archive,session-log,phase-section-part-chapter-area-specs}/**`, edit the claims, but leave address rows that mirror a registered form (A16.4) alone until the address ruling, and keep a quoted sentence of the kingdom address block verbatim and add a dated parenthetical, so the quotes in other files stay true. Hero ledgers stay frozen: a coordinator's message is not the author's permission, so list them as to-do with proposed wording, unless the permission is relayed with the lines named AND the confirmed Chapter Spec's Variance "carriers" note (Audit and Settlement Notes) lists those lines; then edit only those lines (cite the permission as relayed and the note as the disk support), mark each spot with the ruling in italics, leave the address rows that mirror A16.4 alone, and put the dated note in the hero `_index.md` footnote under the pending table (the hero files have no changes section; Sections 10, 12 and 14 are logs and are not used; the footnote is one italic span, so write the mark there without inner asterisks). Append-only Section 12 gets a new numbered row (11 cells, no dimension moved) and the Drift Count line gets an added sentence, never an edit. A Tier B file made before drafting derives only the codes the plan names; a Signature the plan does not name is not invented (all slots `OPEN-AUTHOR`, say so in the file, the pending table and the report), and a Voice Register with no sentence-level evidence stays `OPEN-AUTHOR`. A Tier C row derives the core-six only where the plan names a code; otherwise `OPEN-AREA` with "plan evidence on record, no catalog code picked". Compute the 291 tally by Layer and re-add it; check each new table row with the cell-count Grep. A planner-proposed gender is marked proposed, never `[ASKED]`. A new location file made with Write is LF although most location siblings are CRLF (four recent ones are LF). **Wall-opening ruling on the frozen hero files (the Chapter 008 step, 2026-10-22):** add a second dated blockquote block after the first exception block at 11.4a (Settled; What it allows, numbered; What stays walled; Settled and open; What this ruling amends; What is not touched) and put a one-line dated pointer on every line that restates the wall; find them by Grep (`never appears as thought or word`, `stays unnamed`, `unnamed-imposer`, `convicted`, `OPEN: deferred`) and check each hit carries a pointer on its own line; amend in place only an origin or derived cell (summarise the dropped wording), never a Signature behavior sentence (add a reading note); the authoritative home outside the hero files can carry a mirror (`sol-star-system.md` "Deliberately left open"): add a dated note and flag it; hero index: the two rows' Last Updated cells, the header date and one appended sentence in the footnote (no inner asterisks; verify with `X[^*]*\*$`); edit serially within a file (two parallel Edits both persisted, but it is a race). A pre-registered named-item row takes the long ledger name as Entity Name, the page's short form as Alias, First Area `Not yet established` (the Gate 2 sets it), Type `other item` when no relic home entry exists (flag the edge), and a collision note for common words (the Manual Ledger uses "Seal" as an ordinary word). When the clock rolls over mid-task, Last Updated takes the new date and each ruling keeps the date the author gave it.

**Pre-draft step for a place with no file yet.** The code block needs a host, so make the place file (Write is LF), its registry row, its compliance row, the parent's pointer clauses and a dated Events Log row in the same step; rooms or halls the author lists are pointer rows (12 cells) counted in the index header (verify with `^\|[^|]*\|([^|]*\|){11}\r?$` = rows + 2 for header and separator; files plus pointer rows = Total Entries). Cite only the Chapter reference and the ruling's date. Mark a planner's default that stood at the confirm as `[DERIVED]`, Settled by default, flagged. An address ruling reaches every mirror of the old "no form exists" sentence (the kingdom address block bullets, the hero's address row, the hero index row and footnote) as dated parentheticals, never as rewrites; list the hero files the permission does not name as to-do.

**Pre-draft fact correction of a registered kill state (Tier B file, reusable).** The catalog value `-01` of `L25-KILL` means "Has not killed", so an author ruling that he has killed moves the line to `-99` (AUTHOR-SPECIFIED, `[ASKED]`, the detail `OPEN-AUTHOR`) and names `-01` only as history; retire the first-kill row of 11.6 as `[N-A]` (the Wulfric Rask file is the precedent) and leave the P-row of Section 12 as written; add one 11-cell Section 12 row (`C1`, a correction, no dimension moved) with the old value summarised, an italic note under the table, a sentence added to the Drift Count line, and a Section 10 row. Amend the Section 1 "no combat history" bullets and the canon-decision line in place with a dated ruling mark. Recount the 11.1 tally by Grep (one count per tag, sum 291; a file's own tally can already be one off). A Section 14 missing from the file is created at this step. A spec's "row note" in `characters.csv` has no cell (12 columns, Rule 42.11.1.2) and a commission changes none of its mirrored cells: write none and say so. Prove the `\r` Grep on a known CRLF file before trusting a zero. The side index compliance row (drift rows "1, 2, 6 DERIVED") and the Chapter Spec's Behavioral Plan still name the old code: list them and edit neither.

**Pre-draft codes, kit rows and an open flip.** A location code replaces the file's stub block (`## Collective Behavior Code ...`): the author's provisions go under "For locations only", the other fields point to the ruling-state code or read `OPEN-AREA`, with a Section 4 row, version bump, Changelog and the registry and lore-status rows of the location `_index.md` (CRLF). A formation with no file gets a new section in its military taxonomy file (the Azure Sky patrol block is the precedent) plus dated amendments to that file's "writes no code" sentences. `None, by the author's ruling` goes only to the bodies the ruling names; a planner's reading is not a ruling. A hero "Still pending" pointer is edited only in the hero file the relayed permission names (one clause, ruling in italics, one dated sentence in the hero index footnote); the sibling heroes' pointers are listed as to-do. Manual Ledger rows for a Tier B person: `char_id` is three letters, the first two consonants of the first name plus the surname initial (CRV, KLR, MXP, WLR, GNS, MGD; a few older ids keep a vowel, so the pattern is loose: Grep `^XXX,` and `,XXX,` over the CSVs first); `affinity` is `<Type>:<level name>`; kit `source` is `ORG:<institution>`; `L-2` unless the ledger records a teacher; `mastery` is a flagged DERIVED pick; a Signature manual's LINK-PRIOR means the next lower grade, so a lone Signature kit row reads E3 unmet (information, say so); a Brackenhold Signature row is RANKED and RESTRICTED, and only the Intermediate and Advanced rows lend; note cells hold no comma, em dash or markup; check cells with `^[^,]*(,[^,]*){7}$` (kits) and `{11}` (characters) and the trailing newline. Flipping a derived line to `OPEN-AUTHOR` moves: the Section 11 header counts, the line and the Layer open line, the coverage tally and Layer sums, the 11.2 flags, the 11.3 text (old value kept as history), a Section 10 row, a Section 12 italic note (no log row), the index Tier B, pending and registry cells, and the Changelog. An author ruling that replaces a flagged `[DERIVED]`, Settled-by-default code line: replace the line in place (`Author ruling <date>`, `[ASKED]`, Registered), keep the old wording as a separate dated superseded paragraph and describe its old markers in words (so a `[DERIVED]` Grep finds no pending flag), amend every sentence that says it "rests on a default" (Code Status, the pointer-block header note, the open-items row), add an Events Log row, bump Last Updated and the version, add a Changelog paragraph; in the location `_index.md` (CRLF, single-line Edits) change only the host's main row (date and version cell; pointer rows keep their own version), the pointer row that cites the line, the lore-status row and the header date; the Chapter Spec's own Settled-by-default note is the spec agent's, so report it. **Several codes at once (the Chapter 009 step, 2026-10-22), reusable:** a code the author accepts "as proposed" is `[ASKED]` with that wording in the italic note above the block, and each block is the location-form template (note, Code Status, Applies to, Members, the provisions with a "Basis, from this ledger only" quote copied exactly from the file, forbidden-by-custom `OPEN-AREA`, deviations, group-scene test) plus a Section 4 row (`P.S.N.CCC — Title (ledger step before drafting, <date>; no Chapter written)`, 4 cells, cell-count Grep), a header date and version bump, a Changelog line, and the registry row cells in the location `_index.md` (date, version, one status clause; 12-cell Grep). A place the Chapter Spec leaves as a one-person thoroughfare keeps its stub (Part 37 Area 2.4 addendum fills a stub only when two or more named characters stand there); record the author's "none" in the parent place's block and Events row and report the choice, do not write a `None` line there. A reconfirmed `None` keeps its line and gains one dated italic note, a row, a version bump and a Changelog. Faction files carry `Ledger Version: 10.0` as the folder's format version (never bump it, say so in the Changelog); location files carry `v1.N` and are bumped. A paired-command or "no colour" ruling reaches many mirrors: Grep the stale phrases over story-memory with `!**/{_archive,session-log,phase-section-part-chapter-area-specs,ledger-manuals}/**`, point the file you own at the head note with dated pointers, and report the hits in other ledgers (character files are never edited without the relayed permission). Edit serially within a file (two parallel Edits persisted again, but it is a race). Never repeat a held matter's content in a file or a report; verify by Grep that the held words are absent.

**Tier B file from an interview packet (speaking non-viewpoint person, pre-draft; the Dalsen step, 2026-10-22).** Shape: `max-pryce.md` (partial, interview-based, 14 sections, open dimensions listed by mnemonic per Layer) with `wulfric-rask.md` for the ideology/psychology/drift-row wording. The relay drops the planner's packet (derived defaults, question numbers, evidence): recover it from the session `.jsonl` (the planner's SubagentHandback line; Grep a unique phrase with a window under 200 chars, then Read that one line). Verify every code twice (Appendix B dimension list, then the option table by Grep `^\| \`B39-Lnn-DIM-nn\``). Where the packet gives words and no code, pick the nearest option, mark it "Recorder's pick" with alternatives and list it under the Registration flags; `L31-IMMUTABLE` has no Layer L15 option (use `-99`); an immutable that carries `L34-END-04` is a coherence note for the author (the catalog's match is `END-01`), not a change. L34 cells the packet did not give read `OPEN-AREA` (do not import an earlier interview's STATUS-05/KNOWN-01 defaults); `L34-STATUS-01` can cite a written page of an earlier Chapter (Grep it, whole-built form "Area block NN"), so do not substitute it. Core/Operational/Surface beliefs the author did not give stay `OPEN-AUTHOR` with the stance recorded. Drift rows: a row the packet names no change for is "mapped" as `author-ruled at Check #21` (Rule 39.42.3.1), no change invented. Count the tally per Layer and re-add to 291. The index and Manual Ledger lanes write in parallel: re-Grep the CSVs and the index just before closing the Manual Kit line. Faction pass: a dated pointer on every sentence that says no realm is assigned to the post (the person's level is not the post's), plan-baseline notes on the open items the plan engages (11a, 20(v)) that record no answer, an Events Log row and a Changelog line; list the mirrors outside the write set (`ledger-worlds-kingdom-state/gale-kingdom.md` Key NPCs) instead of editing them.

**Role migration (Tier B side person to Tier B villain; no delete tool).** Write the villain file first, then overwrite the old side file with a pointer stub and ask for `git rm`. Touch-points: side index header (Total Entries prose in three spots: count, Tier B number, "pointer rows" clause, "N entries of Tiers A to C"), Tier B row to a 12-cell pointer row, annotation, address-table row, pending row deleted (anchor the Edit on the previous row's tail), Part 39 status row (7 cells) to a pointer, the "not one of the fourteen" paragraph, the Tier B compliance row (4 cells); villain index header Total Entries, Tier A/B row (8 cells; the table header equals the unmapped table's, so anchor on the italic note), the Tier D note sentence that named the old home, pending row (4) and its footer count, Part 39 registry row (6) and footer, compliance row (5) and footer; pointer paths in the faction code (members and deviations lines), the named-moves Users cells (CRLF), the kingdom-state Key NPCs line and the king's file; bump Last Updated and add a Changelog line in each file touched. A blanket "accept the digest's recommended values" reaches the items it lists: an asked line it does not name is written `[DERIVED]` and flagged, and said in the report. A rewritten voice scope goes in Section 12 as an italic note (no log row), with the PSM mapping flagged as the recorder's reading. Never send a placeholder new_string (a draft Edit with one failed only because its old_string was mistyped).

**Line endings.** Edit keeps a file's own endings; Write makes LF (note it). Verify: LF files `\r` count 0; CRLF files `^.*[^\r]$` count 0. CRLF: `ledger-worlds-location/`, `ledger-worlds-kingdom-state/`, travel and distance `_index.md`, named-moves index, `azorion.md`, `azure-sky-palace.md`, Section Spec, `chapter-003-spec.md`. LF: hero, side, villain, faction, calendar, named-items indexes, Part Spec, spec registry, Chapter 001 and 002 specs. This list drifts; check. Exceptions seen: `ledger-worlds-location/highgale.md` is LF among CRLF siblings, and `ledger-people-society-affiliation/northern-accord.md` is CRLF among LF siblings. An empty bare-LF line passes `[^\r]$` (it has no character before the end); the proof that catches it is a multiline Grep for `[^\r]\n` (count 0 on a CRLF file; it counts every line on an LF file). Check the first character of a multi-line Edit insertion the same way.

**World, kingdom and faction pass (a whole-built Chapter, lane 2b).** Read the Chapter Spec's Open note "ledger entries owed" first. A road and its named parts (ford, stair, narrow, hut) sit in one road file with pointer rows (Lower Road precedent); a ford that hosts a whole fight gets its own file; a pass named once is a section of the range file plus a pointer row. A page place is recorded only as the page gives it; the plan's reading is named as the plan's (a planner's frontier is a plan fact, never a page fact). Kingdom-state `First Area Appearance` is the first NAMING (the location file's header is the check), not the first scene; fix a registry row that disagrees with its entity file. A ruling that supersedes ledger text (address, a ring's name): dated head note at the block, short dated notes at each stale row, old wording kept as history, carriers counted by Grep `-o` per speaker and line, Locked-Canon claims it sets aside flagged to the author; offices the ruling does not name are not retired. Tech ledgers (`ledger-technology-scale`, `-vehicle`) hold "file on first described use" pending lists: the Hourline precedent is a named-item row only, so add a dated note and flag the file question rather than invent a tier. Check letters and speeches that restate an earlier Chapter's facts against the written Chapter (dates of deaths) and report a mismatch, changing no ledger. One Edit at a time per file; parallel Edits on one file persisted but are a race. Check lane work already on disk (Tier D rows, substance register) by Grep before claiming it. The energy-relics index is CRLF. Pin every quoted line to its Area block by the `<!-- AREA NN -->` marker line numbers (Grep `-n`) before writing "Area block NN" (a speech just above the next marker belongs to the earlier block), Grep the page before any negative claim ("not named in the narration", "never shown": a first draft said a kingdom was unnamed while the narration gave its rulers' titles), and attribute each quote to the speaker who says it. The Current Character Position Registry sits in the location `_index.md` and belongs to the world lane: update the heroes the Chapter shows from the closing lines of their last block and claim no posture or furniture the page does not give (read who sits where); earlier Gate 2s may have skipped it, so report rows left behind rather than repair other Chapters' rows. A 12-cell registry edit is checked with `^(\| [^|]+ ){12}\|\r?$` (rows plus header) and the position table with `{5}`.

**Characters and people lane (whole-built Chapter), reusable.** Recover the first Gate 1 report (Check #21 enquiries, Signatures per Area block) from the main session `.jsonl`: Grep a unique token with a window under about 200 characters, then Read that one line. Order inside a hero file: Section 9 narrative summaries run oldest first (add the new one last), Section 13 summaries run newest first, Section 10 rows are chronological; a misplaced insert is fixed by deleting the block with a long exact `old_string` and re-adding it where it belongs. A hero file no Gate 2 ever read shows `OPEN-AREA` under 11.3a: open the Owed Beats table by code Grep (UNSEEN, WEIGHT, COST; MASK only where a divergence is registered; MECH-10 and SEAM-01 as registered). An author ruling that supersedes Section 7 address text gets a first-use address note in Section 7 and a Deferred row, not a rewrite of the block, unless the permission names the lines. A Tier D person whose page gives no pronoun has gender `OPEN-AREA` (say so in the notes paragraph). The ROLE token of a Tier D code is often not a page word: Grep the Chapter for each ROLE word before the notes paragraph claims it. Verify Tier D codes by Grep `-o` of `ROLE-[A-Z]+, [^|`]*CPT-N` over the hand-off and the index and compare the lines in order; verify rows by the cell-count Grep. A stale clause that repeats (a Max Pryce affinity type) is Grepped by every phrase variant over the index (registry row, annotation, pending, compliance) and mended with one dated correction-of-record note. A shared faction index is edited by two lanes: re-Grep the row just before each Edit. A mid-task coordinator message can add a register item (the Substance Introduction Register); do it before finishing. A failed Edit with "string not found" often means the anchor starts with a bracket the original lacks.

**Hero lane for a Chapter with Check #21 rulings (Bison, Chapter 008), reusable.** Order of work: update law and schema guardrail, the written page (quote-check every line against it), the hero file in chunks, then the Edits top to bottom. Count deferrals per item across the Deferred rows (the rolled-back first row is not counted); a ruling that names only some flagged items leaves the rest unruled with no counted deferral, and the new Deferred row says so. A flagged item the ruling closes (a register-break candidate) gets a dated note beside its Section 1 bullet, a pointer on the element heading, the pending-row note and the Compliance row; a DEFER again needs only Section 12 and the pending rows (the Chapter 006 precedent). An Owed Beat the Chapter Spec plans may be entered "Shown" on the recorder's reading when the page shows the conduct but not an event the code names; say in the 11.3a note that it is the Gate 2 lane's reading and not a ruling. Never join two sentences or a split sentence into one quotation (a sentence cut by a speech tag is quoted whole or as a fragment). The hero `_index.md` is edited by two hero lanes at once: Edit warns "modified on disk" yet applies cleanly; anchor on unique substrings, re-Grep the rows, and append your own sentence after the other lane's at the end of the footnote (check `X[^*]*\*$`, no inner asterisks). Tell the coordinator when you added a footnote sentence the scope did not name.

**Villain, place and spec-sync pass (whole-built Chapter, one batched Gate 2), reusable.** Plan nouns can differ from the page: Grep the written Chapter for every plan word (tower, castle, a form of address, a kingdom) before a ledger line repeats it, and write the page's wording with a note that the identification is the plan's. For a villain's first acting appearance, put the page lines in a Section 10 row, flip the Owed Beat to "Shown in P.S.N.CCC", add an italic Section 12 note (Drift Count 0, no log row) and replace each "PLANNED, not established" line with what is established; read slots beyond the Gate 1 planned set from the page and label them the recorder's reading. A Brackenhold-style held matter: record the title-only line and the unattributed far-ford sight with "no identification", and state the plan's purpose as the plan's. The Chapter Spec sync model is the last COMPLETED sibling spec: header trio (Spec Status, Spec Version with Completed, Last Updated with Last Sync), Area status per block (anchor each Edit on the block's Planned outcome line), "each of these is planted in the written Chapter, P.S.N.CCC" on every Planted here line, section 6 (Final Variance Summary with the measure figures, differences D1..Dn, Reader now knows, Chapter digest) and a last "As-built sync" group in section 7; the pre-filled Fired cells are read against the page, not trusted.
