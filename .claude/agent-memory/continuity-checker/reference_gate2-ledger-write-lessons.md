Chapter-specific facts live in the specs, ledgers and session-log. Re-verify against the files.

**No shell.** `manual_ledger_query.py validate` cannot be run; predict it and ask the command to run it when a Manual Ledger cell changed. A script change goes to the author first (Part 42 Rule 42.14.1.4).

**References.** Whole-built Chapter: Chapter ref only (`P.S.N.CCC`); cell form `Chapter NNN — <Title> (Ref: P.S.N.CCC)` with an EM DASH (Grep the existing form first; a hand-off hyphen is shorthand); prose says "Area block NN"; calendar rows per date segment (`P.S.N.CCC (date segment N)`, flashback rows left out of rollups, dates `Y.M.D / PD N`). Area-built: `(Ref: ...)` or `(Area <ref>)` at clause end, never nested, never "(Area 03 ..." digits only; header anchor fields hold only `Area NN — Title (Ref: ...)`. After writing Grep `1\.1\.1\.CCC\.\d` and `\(Area 0\d`. `reset_story.py`: AREA_REF needs five parts (Chapter-only refs are not reset; known gap); it resets "First Area Appearance" columns by header when the cell count equals the header's; its CSV `first_area` step skips `cultivation/`; keep non-table notes out of the calendar Current Position block.

**Write only what the page says.** Check every trade, look, hour, count, quote and Signature code against the written .md (Grep); plan words stay in the spec (descriptor ROLE words are code tokens, say so). Never join two sentences into one quotation; count from the text (squads) and from codes, not memory; conformance by absence is not firing; do not widen a ruling; do not claim a re-audit that did not happen; an identity unnamed in the scene is recorded as taken to be the named person, with the reason; status `Dead` only where the prose establishes it.

**Rulings arrive by relay, in stages.** Write nothing the author has not ruled; a later message can correct or lift a hold (use the last one). A ruling reaches only the items it names; the others stay unruled with no Deferred row. Tier B, C, D are the checker's under Part 43 and may be written at once with reasons. Look for a relayed ruling on disk (spec notes) and cite it so lanes agree.

**Append-only.** Section 12 and Section 14 are append-only, also on an in-place revision: a correction is a new `CHANGE (correction of record)` entry; a DEFER again is a fresh Deferred row (7 cells; create the table if absent); entry numbers continue across a redraft and follow the orchestrator's naming. [EVOLVE] additive: add the clause, a dated ruling bullet and an italic Section 12 note (Drift Count 0, no log row, nothing superseded); the first EVOLVE on a file creates Section 14 (template ledger-schema-law Area 2.1) with a "see Evolution Entry N" pointer on the touched Layer line. [KEEP PROFILE] closes the pending row; mixed rulings sit in one Deferred row's Evidence cell. Classification changes: amend the sentences that use it as a determinant, leave baseline rows as history and add a dated classification note.

**First appearance.** A hero sets First Area Appearance and First On-Page Appearance only when present on the page. Owed Beats are opened per file by code Grep (UNSEEN, WEIGHT, COST for all; MASK only if a public-private divergence is registered; MECH-10 and SEAM-01 as registered); a line reads "Shown" only when the Chapter Spec plans it. Hero Depth Test cell in the hero-index compliance registry at the first scene. Flagged Section 1 items become pending rows. Narrative summary mandate (Part 28 Area 17.4). A new named, described place triggers Threshold L-1 (file, registry row with Parent, compliance row, position rows, parent subsection); a room or feature of an existing building, or a descriptor road, ford or hut, is a section or pointer row (counted in Total Entries and said in the header); a proper-named bridge or road meets the travel-ledger threshold, descriptors do not; a new kingdom is Threshold L-2. A location stub's Collective Behavior Code stays OPEN-AUTHOR until two or more named characters are placed there. Tier D rows: people only spoken of say so; update both header counts and add a paragraph naming new rows; kept rows after a redraft get `pending redraft` cells. Do not print an author-removed concept's name.

**Row patterns.** Manual-borne Named Move: classification `Lineage or school technique`; Entity File = CSV path + move ID + manual ID + "the Manual Ledger owns every value"; Users: Tier C/D to the index registry, Tier B to the character file (a Manual Kit pointer line, no move block, Rule 42.12.4.3), unnamed fighters to the faction file; Naming Checks = `manual ledger <ID>; collision scan by ID and by name <date>; register <...>; move-naming law Rule 42.12.2.3 <date>`; a returning move or item gets a notes paragraph, not an edited row; a manual title on the page needs a named-items pointer row. A whole-built `first_area` takes the Chapter form (the validator pattern accepts only `Area N` or `Not yet established`; expect one C-16 per cell; fix proposed to the author). The cultivation-axis kit line is separate from the weapon `character-kits.csv` line. A new Tier B person's `characters.csv` and `character-kits.csv` rows (Rule 42.11.8.1) are written only from what the ledger supports: when `source`, `learned_via`, `mastery` or the affinity type are OPEN-AUTHOR, flag the rows as owed (Rule 42.11.4.1 bars going beyond the ledger) and write none; Tier B people registered after 2026-10-05 carry no rows, so check the CSVs before promising one. Varya (VRY) and Aegon (AEG) never carry a kit row (Part 42 Rule 42.11.7.1; the validator fails one as C-20): children who drill a Common primer at the rack are floor practice, so write their Manual Kit line as `none` with the learning-plan pointer plus a floor-practice clause, keep the moves' Users cells, and do not read the rule's last sentence as a licence for a row (a first write of such rows was withdrawn on 2026-10-21 by a correction of record). A spec sync's Signatures-fired flip is cheapest as one multi-line Edit per Area table (copy the rows from the Read), then Grep the count of `\| 1\.1\.1\.CCC \|$` against the planned rows. Level facts (Rule 29.12.1.3): hero Section 2 blockquote, Section 13, Section 10 rows, Section 9; Tier D a `Qi:` clause in the Current Condition body. Collision scans: Grep every name with `-i` over story-memory, count mode.

**Lanes and hazards.** Lanes write in parallel: inventory by a date Grep first, spot-check what exists, say what was already there. Trust the written file over the brief and report the difference. The index lane owns the INDEX-ROW cells of Tier A/B people; entity files belong to another lane (heads-up to main first). Re-Grep rows and counts just before each Edit on a shared index; anchor on unique substrings with the changing numbers; one Edit at a time per file; the 8-column separator is a substring of the 9-column one, so anchor on the header row; if a multi-line Edit fails, re-Read the live line. Glob lists oldest first. Never send a placeholder new_string. After a redraft, kept place files may carry archived-build facts: compare each non-author block with the written text, keep author lines, say text was replaced. Stale-quote hunt: Grep story-memory (glob `!**/session-log/**`) for the old phrases. Report differences between page and baseline; do not edit them.

**Pre-draft author-directed ledger step (before `/create-chapter` drafts).** Mark every amended spot `Author ruling, <date>` and keep the old wording only as a dated history note (summarise the dropped text rather than quoting it, so stale-phrase Greps stay clean). A ruling that changes a class or office (a head of a class, a second office) reaches mirrors: Grep the stale tokens over story-memory with `!**/{_archive,session-log,phase-section-part-chapter-area-specs}/**`, edit the claims, but leave address rows that mirror a registered form (A16.4) alone until the address ruling, and keep a quoted sentence of the kingdom address block verbatim and add a dated parenthetical, so the quotes in other files stay true. Hero ledgers stay frozen: a coordinator's message is not the author's permission, so list them as to-do with proposed wording, unless the permission is relayed with the lines named AND the confirmed Chapter Spec's Variance "carriers" note (Audit and Settlement Notes) lists those lines; then edit only those lines (cite the permission as relayed and the note as the disk support), mark each spot with the ruling in italics, leave the address rows that mirror A16.4 alone, and put the dated note in the hero `_index.md` footnote under the pending table (the hero files have no changes section; Sections 10, 12 and 14 are logs and are not used; the footnote is one italic span, so write the mark there without inner asterisks). Append-only Section 12 gets a new numbered row (11 cells, no dimension moved) and the Drift Count line gets an added sentence, never an edit. A Tier B file made before drafting derives only the codes the plan names; a Signature the plan does not name is not invented (all slots `OPEN-AUTHOR`, say so in the file, the pending table and the report), and a Voice Register with no sentence-level evidence stays `OPEN-AUTHOR`. A Tier C row derives the core-six only where the plan names a code; otherwise `OPEN-AREA` with "plan evidence on record, no catalog code picked". Compute the 291 tally by Layer and re-add it; check each new table row with the cell-count Grep. A planner-proposed gender is marked proposed, never `[ASKED]`. A new location file made with Write is LF although most location siblings are CRLF (four recent ones are LF).

**Pre-draft step for a place with no file yet.** The code block needs a host, so make the place file (Write is LF), its registry row, its compliance row, the parent's pointer clauses and a dated Events Log row in the same step; rooms or halls the author lists are pointer rows (12 cells) counted in the index header (verify with `^\|[^|]*\|([^|]*\|){11}\r?$` = rows + 2 for header and separator; files plus pointer rows = Total Entries). Cite only the Chapter reference and the ruling's date. Mark a planner's default that stood at the confirm as `[DERIVED]`, Settled by default, flagged. An address ruling reaches every mirror of the old "no form exists" sentence (the kingdom address block bullets, the hero's address row, the hero index row and footnote) as dated parentheticals, never as rewrites; list the hero files the permission does not name as to-do.

**Pre-draft codes, kit rows and an open flip.** A location code replaces the file's stub block (`## Collective Behavior Code ...`): the author's provisions go under "For locations only", the other fields point to the ruling-state code or read `OPEN-AREA`, with a Section 4 row, version bump, Changelog and the registry and lore-status rows of the location `_index.md` (CRLF). A formation with no file gets a new section in its military taxonomy file (the Azure Sky patrol block is the precedent) plus dated amendments to that file's "writes no code" sentences. `None, by the author's ruling` goes only to the bodies the ruling names; a planner's reading is not a ruling. A hero "Still pending" pointer is edited only in the hero file the relayed permission names (one clause, ruling in italics, one dated sentence in the hero index footnote); the sibling heroes' pointers are listed as to-do. Manual Ledger rows for a Tier B person: `char_id` is the first two distinct letters of the first name plus the surname initial (Grep `^XXX,` and `,XXX,` over the CSVs first); `affinity` is `<Type>:<level name>`; kit `source` is `ORG:<institution>`; `L-2` unless the ledger records a teacher; `mastery` is a flagged DERIVED pick; a Signature manual's LINK-PRIOR means the next lower grade, so a lone Signature kit row reads E3 unmet (information, say so); a Brackenhold Signature row is RANKED and RESTRICTED, and only the Intermediate and Advanced rows lend; note cells hold no comma, em dash or markup; check cells with `^[^,]*(,[^,]*){7}$` (kits) and `{11}` (characters) and the trailing newline. Flipping a derived line to `OPEN-AUTHOR` moves: the Section 11 header counts, the line and the Layer open line, the coverage tally and Layer sums, the 11.2 flags, the 11.3 text (old value kept as history), a Section 10 row, a Section 12 italic note (no log row), the index Tier B, pending and registry cells, and the Changelog. An author ruling that replaces a flagged `[DERIVED]`, Settled-by-default code line: replace the line in place (`Author ruling <date>`, `[ASKED]`, Registered), keep the old wording as a separate dated superseded paragraph and describe its old markers in words (so a `[DERIVED]` Grep finds no pending flag), amend every sentence that says it "rests on a default" (Code Status, the pointer-block header note, the open-items row), add an Events Log row, bump Last Updated and the version, add a Changelog paragraph; in the location `_index.md` (CRLF, single-line Edits) change only the host's main row (date and version cell; pointer rows keep their own version), the pointer row that cites the line, the lore-status row and the header date; the Chapter Spec's own Settled-by-default note is the spec agent's, so report it.

**Role migration (Tier B side person to Tier B villain; no delete tool).** Write the villain file first, then overwrite the old side file with a pointer stub and ask for `git rm`. Touch-points: side index header (Total Entries prose in three spots: count, Tier B number, "pointer rows" clause, "N entries of Tiers A to C"), Tier B row to a 12-cell pointer row, annotation, address-table row, pending row deleted (anchor the Edit on the previous row's tail), Part 39 status row (7 cells) to a pointer, the "not one of the fourteen" paragraph, the Tier B compliance row (4 cells); villain index header Total Entries, Tier A/B row (8 cells; the table header equals the unmapped table's, so anchor on the italic note), the Tier D note sentence that named the old home, pending row (4) and its footer count, Part 39 registry row (6) and footer, compliance row (5) and footer; pointer paths in the faction code (members and deviations lines), the named-moves Users cells (CRLF), the kingdom-state Key NPCs line and the king's file; bump Last Updated and add a Changelog line in each file touched. A blanket "accept the digest's recommended values" reaches the items it lists: an asked line it does not name is written `[DERIVED]` and flagged, and said in the report. A rewritten voice scope goes in Section 12 as an italic note (no log row), with the PSM mapping flagged as the recorder's reading. Never send a placeholder new_string (a draft Edit with one failed only because its old_string was mistyped).

**Line endings.** Edit keeps a file's own endings; Write makes LF (note it). Verify: LF files `\r` count 0; CRLF files `^.*[^\r]$` count 0. CRLF: `ledger-worlds-location/`, `ledger-worlds-kingdom-state/`, travel and distance `_index.md`, named-moves index, `azorion.md`, `azure-sky-palace.md`, Section Spec, `chapter-003-spec.md`. LF: hero, side, villain, faction, calendar, named-items indexes, Part Spec, spec registry, Chapter 001 and 002 specs. This list drifts; check.

**World, kingdom and faction pass (a whole-built Chapter, lane 2b).** Read the Chapter Spec's Open note "ledger entries owed" first. A road and its named parts (ford, stair, narrow, hut) sit in one road file with pointer rows (Lower Road precedent); a ford that hosts a whole fight gets its own file; a pass named once is a section of the range file plus a pointer row. A page place is recorded only as the page gives it; the plan's reading is named as the plan's (a planner's frontier is a plan fact, never a page fact). Kingdom-state `First Area Appearance` is the first NAMING (the location file's header is the check), not the first scene; fix a registry row that disagrees with its entity file. A ruling that supersedes ledger text (address, a ring's name): dated head note at the block, short dated notes at each stale row, old wording kept as history, carriers counted by Grep `-o` per speaker and line, Locked-Canon claims it sets aside flagged to the author; offices the ruling does not name are not retired. Tech ledgers (`ledger-technology-scale`, `-vehicle`) hold "file on first described use" pending lists: the Hourline precedent is a named-item row only, so add a dated note and flag the file question rather than invent a tier. Check letters and speeches that restate an earlier Chapter's facts against the written Chapter (dates of deaths) and report a mismatch, changing no ledger. One Edit at a time per file; parallel Edits on one file persisted but are a race. Check lane work already on disk (Tier D rows, substance register) by Grep before claiming it. The energy-relics index is CRLF.

**Characters and people lane (whole-built Chapter), reusable.** Recover the first Gate 1 report (Check #21 enquiries, Signatures per Area block) from the main session `.jsonl`: Grep a unique token with a window under about 200 characters, then Read that one line. Order inside a hero file: Section 9 narrative summaries run oldest first (add the new one last), Section 13 summaries run newest first, Section 10 rows are chronological; a misplaced insert is fixed by deleting the block with a long exact `old_string` and re-adding it where it belongs. A hero file no Gate 2 ever read shows `OPEN-AREA` under 11.3a: open the Owed Beats table by code Grep (UNSEEN, WEIGHT, COST; MASK only where a divergence is registered; MECH-10 and SEAM-01 as registered). An author ruling that supersedes Section 7 address text gets a first-use address note in Section 7 and a Deferred row, not a rewrite of the block, unless the permission names the lines. A Tier D person whose page gives no pronoun has gender `OPEN-AREA` (say so in the notes paragraph). The ROLE token of a Tier D code is often not a page word: Grep the Chapter for each ROLE word before the notes paragraph claims it. Verify Tier D codes by Grep `-o` of `ROLE-[A-Z]+, [^|`]*CPT-N` over the hand-off and the index and compare the lines in order; verify rows by the cell-count Grep. A stale clause that repeats (a Max Pryce affinity type) is Grepped by every phrase variant over the index (registry row, annotation, pending, compliance) and mended with one dated correction-of-record note. A shared faction index is edited by two lanes: re-Grep the row just before each Edit. A mid-task coordinator message can add a register item (the Substance Introduction Register); do it before finishing. A failed Edit with "string not found" often means the anchor starts with a bracket the original lacks.

**Villain, place and spec-sync pass (whole-built Chapter, one batched Gate 2), reusable.** Plan nouns can differ from the page: Grep the written Chapter for every plan word (tower, castle, a form of address, a kingdom) before a ledger line repeats it, and write the page's wording with a note that the identification is the plan's. For a villain's first acting appearance, put the page lines in a Section 10 row, flip the Owed Beat to "Shown in P.S.N.CCC", add an italic Section 12 note (Drift Count 0, no log row) and replace each "PLANNED, not established" line with what is established; read slots beyond the Gate 1 planned set from the page and label them the recorder's reading. A Brackenhold-style held matter: record the title-only line and the unattributed far-ford sight with "no identification", and state the plan's purpose as the plan's. The Chapter Spec sync model is the last COMPLETED sibling spec: header trio (Spec Status, Spec Version with Completed, Last Updated with Last Sync), Area status per block (anchor each Edit on the block's Planned outcome line), "each of these is planted in the written Chapter, P.S.N.CCC" on every Planted here line, section 6 (Final Variance Summary with the measure figures, differences D1..Dn, Reader now knows, Chapter digest) and a last "As-built sync" group in section 7; the pre-filled Fired cells are read against the page, not trusted. Do not write the parents or their registry rows. A cell the page contradicts (a form of address never spoken) is recorded as not exercised.

**Revision of a written Chapter (a cut clause), Gate 2 lane 2: a verification plus a correction of record.** Grep the exact clause and its retained sentence over story-memory with `!**/{_archive,session-log}/**` (agent memory and session logs hold it and are not canon; a Kind or place file usually quotes the sentence only up to the cut), then Grep each person's, Kind's and place's ledger lines for a paraphrase of what the clause attributed (the speaker's name with told, talk, warned); write no ledger line when none depends on it, and say so. Prove the new figures by per-block token probes on the written `.md` (tokens less 6 per date line, 1 per `---`, 3 per `* * *`), then Grep the old figures and refresh them in the Completion Record, the word-band note and the Scene Map note of the as-built group, keeping "first written text" wording as history. Add the next D bullet in section 6, a variance note and an Audit note in a new last group of Audit and Settlement Notes (name the group in the section's groups sentence), extend the header Last Sync, leave status and version, and confirm rule numbers in the skill (Rule 6.1.1(a): a sync on a revised Area is a correction of record; Rule 9.7.1: completion pieces are refreshed when a COMPLETED spec is revised). A registry row already dated the same day needs no Edit. The scoring aggregate (`cdl2-density-tracking`) quotes the Chapter's figures: report it to the scoring lane and never edit it. Cite the author's ruling and Gate 1's verdict as relayed.

**Spec sync when the author ruled at Gate 1 (whole-built Chapter).** Put each relayed ruling in the Settled group as its own dated note, and mark any Settled-by-default note it overrides `SUPERSEDED on <date>` with the first answer left as it stood (then fix the group's header sentence that counts the superseded defaults). Append `Done at the Gate 2 of <date>: ...` to each Open note the pass closed (the Chapter 006 precedent), and keep the last As-built group for Audit, Variance and Name notes plus one Audit note `Check #21 (as relayed)` that points to the Settled notes and records the Tier B, C and D checker decisions. Write the Standing Exclusions note by reading section 3 item by item and Grepping the page for each "absent" word: a held item can be partly on the page (a tell seen by one parent and held from the other; the man at the rack is not the villain "the man"; a pigeon is not a beast; "spring" can stand in a dating clause). Count a quoted line's words by listing them (a four-word line was first called three). Before closing, re-read the whole page once against every quotation in the new notes (weather and light by Area, dates, who says "Teacher"), and prove the Area counts with one whole-file token probe (`\A\S+(?:\s+\S+){N}` runs at N near 10,900): file tokens = narration words + title block + 4 per marker + date line + breaks.
