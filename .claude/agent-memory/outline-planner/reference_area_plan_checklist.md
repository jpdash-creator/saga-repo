**Checklist before an Area plan leaves.**
1. An entity the viewpoint dwells on is named (Part 28 Rule 20.2 prong 5); a glimpse is a sign.
2. Plan words are not prose words: strip comparatives that foreshadow.
3. Read the viewpoint character's L02 and L07 lines first.
4. Opening type and Carry-over come from the Area block, not the coordinator brief; compare with the last paragraph of the Area before (what is still in whose hand).
5. Word doubles and images used in the Areas before are listed as repeats to avoid.
6. Check #21 flagged items: raised once at the first Area where the character acts or speaks, then at each Area close until ruled.
7. A fully wordless Area needs the Part 2 Rule 2.1 silence clause.
8. A Named Move's first appearance gets the full DP-9 treatment; ban weapon words where a reach must not replay an earlier named cut.

**/next-area two-phase flow.** Phase 1: grounding report under about 400 words, nothing to disk. Phase 2: a mid-task message with the author's answers; write the plan to the session scratchpad as `chN-area-NN-plan.md`; no em dashes or contractions; reply with the path and the Check #21 items. Whole-mode Chapters issue no Area plan.

**Name scan.** Grep the whole repo with glob `!{**/_archive/**,**/agent-memory/**,**/.git/**}`. Hits in agent memory or `.claude/temp` are not canon. Strike echoes of existing names (month names too, such as Melorany) and well-known fiction names. Never carry a zero-hit pool over: rescan each time.
