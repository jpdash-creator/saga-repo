**Fail classes seen (fix these in the first draft).** (1) A dated author ruling inside parent NEW text (provenance belongs in a Settled note of the revision group, not in the plan sentence). (2) Stale audit statements ("light audit not yet run", "no light audit was run before the write") after the audit ran: use the Chapter 007 header style, "run on DATE: FAIL (narrow; N blocking findings, applied); fixes-only re-audit: pending", in the Chapter Spec header, its Audit note and both parents' header and amendment-log notes. (3) "Novel elements carried" names that are not in the Part 36 Area 15.5 Element column (use "Mystery, clues, suspense", "Foreshadowing, payoff, coincidence", "Lore-building", "Relationships, romance" or "Friendship, rivalry", "Emotions", "Chapter endings, cliffhangers"; the auditor and Chapter 007 use these exact names). (4) A guard line that hints at the author-held matter: keep the held-matter bullet to a pointer ("named only by where it lies") and put any guard about the man or the monster king in the reader-only bullet (the P30-L9 bullet) and the Area exclusions ("no word of the man; nothing of the matter the author holds"). (5) A Signature mapped to the wrong thing: `B39-L29-WATCH-99` is "he watches the craft", not the village watch; the standing wait is `B39-L29-WAIT-99` and `B39-L29-SILENCE-99`. (6) Sense rails written as a negative description ("not by any sense that reaches farther"): write the rail only ("no soul-sense reading of the weather is shown"). (7) A spoken-of person group with no row in 5.0a: add "spoken of, none owed". (8) Parent lines that make the author's fact a suspicion: the author said the fathers placed the Seal (a fact); the hidden agenda is the shared suspicion. (9) A Deferred note the author did not give: move to Open. (10) Missing header field: `| **Last Sync:** —` on the Last Updated line of an unwritten Chapter Spec.

**Named-item italics pass.** When the author rules an item named, one `replace_all` of "the Seal" to "the *Seal*" does most of the work in the Chapter Spec; then fix by hand the capital "The Seal", "a Seal", the full name, the Names note, the register-row duty (Open note item, Settled ledger-work note, Area "Ledgers expected to change", Debuts) and revert the verbatim quotes of a higher text ("Original beside it" quotes and quoted law words stay roman). In the parent edit lists, change only the NEW blocks and notes; OLD blocks stay verbatim. Grep `[^*]Seal` afterwards: what is left must be OLD text, quotes or a Part 30 note title.
