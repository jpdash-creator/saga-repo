> **Purpose:** This folder tracks the canonical state of locations that appear in the novel — worlds, regions, cities, structures, Sacred Grounds, dimensional anomalies, and other classified locations of narrative significance. It also serves as the authoritative record of character location state (where major characters are at any given point in the narrative) and active travel state (ongoing journeys, transit routes, FTL trajectories).

> **Entry Categories:**
> - **Location Files:** Individual files for named locations of narrative significance — tracks Part 13 classification (world type, area tier), ambient energy class, Sacred Ground grade if applicable, current controlling faction, and key events.
> - **Active Travel Record:** A table in this index (section Active Travel Records) tracking all ongoing journeys — which characters are in transit, from where to where, by what method, and estimated arrival. Updated every Area involving travel.
> - **Current Position Registry:** A table (in this index file) showing the current canonical location of all major characters (hero, villain, Tier A side characters) at the current narrative position.

> **Update Protocol:** Per `guardrails/ledger/guardrail-ledger-update-law.md`, the Pre-Write Ledger Check reads current location state from this folder before any prose set in a classified location. Location changes (characters moving between classified locations), Sacred Ground formation or destruction, and dimensional rift opening/closing trigger mandatory Post-Write Ledger Update. Journey completion and arrival at a new canonical location trigger updates to both this folder and the relevant character's ledger Section 10 (Canon Events Log).

> **Command Interface:** [STATUS] (C-13) reports current narrative location from this ledger. [RUN CANON AUDIT] (C-10) cross-event consistency check includes location state against character ledger position records.

> **CS%/TS% Tracking:** CS% (Cultivation Synergy %) and TS% (Technology Synergy %) for each location are Living Information (L) stored in the location's Section 2 (Spatial Data) per Part 31 Area 21.5–21.7 and 21.13. Values range 0%–100% per Part 31 Area 21. The Location Registry table includes CS%/TS% columns for quick-reference cross-audit. World-tier CS% is governed by Part 13 World Classification and ambient energy class. Cosmic-entity CS%/TS% shifts on civilizational timescales and is updated when CTD (Civilization Tier Designation per Part 21) transitions occur for controlling civilizations.

> **Marker Legend:** These markers appear in the entries of this ledger. Open cells otherwise carry `OPEN-AREA` or `OPEN-AUTHOR` (Part 37 Area 5).
> - `[ASKED]`: the author chose this value.
> - `[DERIVED]`: the drafter inferred this value from cited evidence and the author reviewed it in the digest without overriding it (Part 39 Rule 39.3.3.1); it is pending only when the entry also says flagged for author confirmation.
> - `[AUTHOR-PENDING]`: a question about this value has been raised and is not yet answered.
> - `[MARKED SLOT]`: a slot left empty on purpose until the author rules.
> - "flag, do not invent": when a scene needs the value, the prose may establish one small fact at a time under Part 28 Area 17, logged in this ledger and offered to the author as a draft value at the next Section close. A name or a major entity (Part 28 Area 20.4) goes to the author first, through the Decision Consultation Gate.

## Part 28 Area 17 — Lore Section Schema (Location Domain)

Axes 13 and 14 are part of the schema. Every location file gains them when it is next touched; until a file records them, each reads open (Part 28 Area 17.3).
**Governing Law:** Part 28 Area 17 (Lore Creation Law). **Audit Hook:** ALCA dimension AL-10 (Lore Completeness Alignment; `guardrails/audit/guardrail-alca.md`).

**Mandate:** Every location entity file in this ledger must carry a dedicated **Section 5 — Lore (Part 28 Area 17)** block populated to the Breadth-and-Depth Standard (Part 28 Area 17.3). Background (non-narratively-active) locations may be populated to the Proportionality Exception depth (Part 28 Area 17.3); narratively active locations (hero homes, Phase-1 setting locations) must meet full breadth-and-depth. A file whose full lore sits in a parent file may read **CROSS-REFERENCE ONLY** and name the parent file and sections that hold it (sapphire-basin.md points to azure-sky-kingdom.md §5.1 and §5.8).

**Required Axes (Minimum Lore Fields per Part 28 Area 17.2 — World/Star System/Continent/Kingdom/City/Village/Sub-Location):**

1. **Geographic Extent** — area, population-bearing region, borders or territorial limits, topography in enough detail to ground a scene at the Part 28 Area 17.3 depth.
2. **Founding History** — when established, by whom, under what circumstance, named founder(s), founding event.
3. **Ruling Authority** — current governing body, succession mechanism, known historical ruling lineages, named past rulers where known.
4. **Dominant Culture** — governing Part 25 CPT, dominant linguistic/aesthetic register, named cultural traditions, festivals, taboos.
5. **Cultivation Profile** — Part 3 power distribution, sects present, highest-known realm, Firmament Lock interaction if applicable.
6. **Technology Profile** — Part 8 TA tier, domain specializations, signature technologies, named technology products or institutions where known.
7. **Ambient Energy Class** — per Part 13 Area 2.3 classification.
8. **Notable Landmarks** — named sites, named districts, named infrastructure, at least three scene-seed landmarks per narratively active location.
9. **Diplomatic Posture** — Part 23 affiliation positions with neighboring entities, named treaties, named rivalries.
10. **Population Estimate** — order of magnitude, composition (cultivation practitioners, technologists, common populace, non-human or sub-species population if applicable).
11. **Economy Primary Drivers** — what the location produces, trades, imports; named trade routes where known.
12. **Distinctive Architectural/Sensory Signature** — what a visitor first notices — materials, colors, sounds, smells, skyline, ambient soundscape, light quality.
13. **Climate and Seasonal Texture** — per Part 13 Area 27: the climate belt, the seasons and what each does to the place, the weather and the storm, wind, rain or drought regimes a visitor meets. Facts a scene establishes are recorded here and hold (Part 13 Area 27.3).
14. **Hazards and Dangers to a Visitor** — what can hurt a traveller there: terrain, weather, wildlife, ambient energy, disease, patrols and frontier risk, unrest.

**Depth Test (Part 28 Area 17.3):** "Can I write a pacing-appropriate immersion scene (Part 28 Area 17.3) in this location using only what is in the ledger?" If yes, depth is satisfied. If no, expand.

**Proportionality Exception:** Strictly background locations (named but not narratively active) may populate axes to internal-consistency depth only. Promotion happens in the Post-Write Ledger Update of the first scene set there (Part 28 Area 17.4 step d); drafting is not blocked by a STUB file.

**Silent Overwrite Prohibition (Part 28 Area 17.5):** Once lore is recorded in this ledger, it is fixed under the Establishment Threshold. Retroactive enrichment is permitted; retroactive contradiction requires a formal Canon amendment.
