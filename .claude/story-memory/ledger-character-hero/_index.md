**Index Version:** Canon v10.0
**Total Entries:** 8

> **Purpose:** This folder contains one ledger file per protagonist hero character in the Starward Saga series. Each file uses the 13-section Character Ledger Template defined in Part 37 Area 2.3. Sections marked (B) contain Base Information — immutable foundational data established at character creation. Sections marked (L) contain Living Information — continuously updated as prose is written.

> **Update Protocol:** Per `guardrails/ledger/guardrail-ledger-update-law.md`, this index is updated every time a new hero ledger file is created or an existing hero's status changes. The Pre-Write Ledger Check reads hero ledger entries before any Area involving that hero. The Post-Write Ledger Update updates hero ledger entries after any accepted Area that changes hero state.

> **Mandatory Update Triggers (Per Part 17 Area 6.3):** Cultivation/tech breakthrough; significant combat outcome; IE-3+ ideology event; PIS-3+ psychological event; CSS-3+ consequence event; significant relationship change; faction position change; CS%/TS% triggering events per Part 31 Area 21.4.2 (Integration Model change, realm breakthrough, Sacred Ground extended cultivation, CI Technology architectural integration or loss).

> **CS%/TS% Tracking:** CS% (Cultivation Synergy %) and TS% (Technology Synergy %) for each hero are Living Information (L) stored in Character Ledger Section 2. Values range 0%–100% per Part 31 Area 21. The _index.md registry includes CS%/TS% columns for quick-reference audit against the full ledger file.

> **Phase 1 End-State Power Levels (Part 30 Section 1.3.1 — Locked Canon):** All 8 hero ledgers now carry canonical Phase 1 end-state cultivation levels in Section 9 (Sections 1 and 2 say `see Section 9`). These are Locked Canon per Part 28 and govern the Phase 1 story trajectory. The "Phase 1 End-State" column below reflects these targets for quick-reference.

> **Marker Legend:** These markers appear in the entries of this ledger. Open cells otherwise carry `OPEN-AREA` or `OPEN-AUTHOR` (Part 37 Area 5).
> - `[ASKED]`: the author chose this value.
> - `[DERIVED]`: the drafter inferred this value from cited evidence and the author reviewed it in the digest without overriding it (Part 39 Rule 39.3.3.1); it is pending only when the entry also says flagged for author confirmation.
> - `[AUTHOR-PENDING]`: a question about this value has been raised and is not yet answered.
> - `[MARKED SLOT]`: a slot left empty on purpose until the author rules.
> - "flag, do not invent": when a scene needs the value, the prose may establish one small fact at a time under Part 28 Area 17, logged in this ledger and offered to the author as a draft value at the next Section close. A name or a major entity (Part 28 Area 20.4) goes to the author first, through the Decision Consultation Gate.
